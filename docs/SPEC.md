# てすとも君（解答用紙メーカー）仕様書（v1.0 確定版）

作成者と担当AIの対話で確定した仕様。実装者はこの文書を唯一の仕様として扱うこと。
不明点があればここに追記して合意を取る。仕様にない機能は追加しない（「機能もりもりより一目瞭然」が最優先）。

---

## 0. 一言でいうと

中学校（高校でも使う）の教師が、定期テストの **解答用紙と模範解答を、キーボードだけで3〜5分で作る** ツール。
ブラウザで開く **単一HTMLファイル**。オフライン・通信ゼロ。出力は **Excel(.xlsx) が正本**、PDFは確認用。

作成者が自作していた「マクロ付き国語解答用紙Excel」（`docs/reference/` 参照）が完成形のお手本。
その **印刷範囲（B1:AA48）をそのまま再現できる** ことが到達点。

## 1. 形式・制約（絶対条件）

| 項目 | 決定 |
|---|---|
| 配布形態 | `answer-sheet-maker.html` 1ファイル。ダブルクリックで開く。将来 exe に包める構造にする |
| 通信 | ゼロ。fetch/XHR/外部CDN/外部フォント/画像URL いずれも禁止。ライブラリは同梱 |
| 依存 | 圧縮（JSZip 程度、約100KB）のみ同梱可。xlsx は OOXML を自前生成（SheetJS 無償版は罫線・印刷設定が出せない、ExcelJS は重い） |
| 用紙 | 必ず **A4・1枚**。縮小しない。収まらないときは置けない＋警告 |
| 余白 | 既定は作成者Excelの実績値（左右 8mm、上下 9mm）。⚙で 10mm / 12mm を選択可 |
| 図形禁止 | マス・番号・答え・得点枠はすべて **セル罫線とセル文字**。テキストボックス等の図形は使わない（出力後にExcelで手直しできるようにするため） |
| 縦書きセル禁止 | Excel の縦書き（textRotation=255）は長音・句読点・拗促音が崩れる。**1マス1文字** で縦に並べる。タイトルと氏名欄も同様 |
| フォント | ワークブック標準フォントを固定（游ゴシック 11。無ければ MS ゴシック）。画面は system-ui |
| 保存先 | 作業ファイル(.json)はユーザーのPCにダウンロード保存。自動バックアップは localStorage（後述の機密配慮あり） |
| 対象環境 | Windows の Edge/Chrome。マウスなしキーボードだけで全操作が完結すること |

## 2. 用紙とマス目（お手本Excelの実測値）

### 2.1 お手本の実測値

- 印刷範囲 `B1:AA48`、A4 横、印刷倍率 80%、印刷位置 水平・垂直とも中央
- 列幅（Excel単位）：B=3.25、C〜N=6.125（12列）、O=2.375（区切り）、P〜R=6.125、S〜V=7.375、W〜Y=6.5、Z=5.75（氏名欄）、AA=9（タイトル）
- 行高：1行目 12.95pt、2〜48行目 13.5pt
- **1文字 = 2行（13.5pt×2）**、番号ラベル（問一・(1)・①）は 1行
- 80%印刷後の実寸：1文字マス ≒ **幅10.2mm × 高さ7.6mm**、番号行 ≒ 3.8mm
- 右端：`Z2:Z47` 結合＝氏名欄（16pt）「一年　　組　　番　氏名（　　　　）」、`AA2:AA43` 結合＝タイトル（18pt）「第１学年　学年末テスト　解答用紙」
- 2行目：大問番号「八 七 六 五 四 三 二 一」（14pt、各ブロックの先頭列）
- 3行目：小問ラベル「問一」「(1)」「①」（11〜14pt）
- 左下 `W29:Y47` 付近：得点枠「合計 100 / 思・判・表 50 / 知・技 50」（お手本では図形。**本ツールではセルで再現**）
- 記述欄末尾の固定文字例：`H37:H46` に「から。」（縦書き）

### 2.2 本ツールのマス目

お手本の値をそのまま採用する（実績があり、印刷で寸法が保証されているため）。

| 教科 | 用紙 | 文字方向 | 大問の並び | 列幅 / 行高 | 印刷倍率 |
|---|---|---|---|---|---|
| 国語 | A4 横 | 縦書き | 右 → 左（問一が右端） | 6.125 / 13.5pt | 80% |
| 数学・英語・理科・社会・その他 | A4 縦 | 横書き | 上 → 下、左 → 右 | 6.125 / 13.5pt | 80% |

- 画面のマス目 = Excel のセル。**1文字マス = 縦2セル**（縦書き）／横書きも 1文字 = 幅1列 × 高さ2行 で統一
- 最小マス 8mm。これより小さくしない
- 縦書き用紙の収容量：欄用の列 約24列（氏名・タイトル・余白を除く）、行 48
- 教科・向き・文字方向・番号スタイルは ⚙ で後から変更可（高校・社会の縦書き等）

### 2.3 新規作成時に自動配置するもの

- タイトル（教科・学年・テスト名から生成。例「第１学年　２学期中間テスト　解答用紙」）
- 氏名欄（既定「一年　　組　　番　氏名（　　　　　　）」。並び順は ⚙：年組番氏名／組番氏名）
- 得点枠：合計 / 知・技 / 思・判・表（各セル）。位置は縦書き＝左下、横書き＝右上。⚙で ON/OFF
- 配置場所はお手本と同じ（縦書き：右端2列にタイトル・氏名）

## 3. 欄の型（数字キー 1〜7）

> **この節は §17.1 で置き換えられている。** 欄は 1〜5 の5種類。`T` キーも廃止（線の太さは Shift+1 / Shift+2）。
> 以下は v1.0 時点の記述として残す。

| キー | 型 | 形 | 作成時に聞くこと |
|---|---|---|---|
| 1 | 記号（一文字） | 1文字マス 1つ | なし |
| 2 | 記号（複数） | 1文字マスを n 個縦（横書きなら横）に連結 | 個数 |
| 3 | 漢字・語句 | 1文字マス n 個、区切りは点線、外枠実線 | マス数（既定 2） |
| 4 | 記述（字数指定） | 1文字マス n 個。「以内」なら **8割ライン** | 字数、以内／ちょうど（既定 以内） |
| 5 | 答えのみ | 横長の1欄（縦書きでは縦長）。前置き・後置き文字可（「x＝」「cm²」） | 欄数（既定 1）。前置き・後置きは後から入力モードで |
| 6 | グラフ・作図 | 白枠 / 方眼（5mm 相当。方眼線は細い破線） | 白枠／方眼、大きさ（列数×行数） |
| 7 | 自由記述枠 | 罫線なしの大枠（途中式・証明） | 高さ（行数） |

共通：
- 欄は **矩形の集合**（記述が複数列に分割されるため）。番号は欄に1つ
- 記述の字数が列の残りに収まらないときは自動で複数列に分割（例：50字 → 25字×2列）。8割ラインは全字数の8割位置を列に換算して引く（50字なら40字目＝2列目の15字目）
- 作成後、カーソルは「次の位置」（縦書きなら同じ列の下、列が尽きたら左の列の上）へ自動移動
- 小問ごとに **配点**（既定＝大問配点÷小問数）と **観点**（知技／思判表、既定は大問の観点）
- T：選択範囲の外枠を太線（完答）。Delete：選択範囲の罫線と文字を消す

罫線の種類は3段階に固定し、Excel罫線にそのまま対応させる：

| 用途 | 線 | Excel |
|---|---|---|
| マス罫線・欄の外枠 | 細実線 | thin |
| 完答・大問の外枠 | 中太実線 | medium |
| 文字区切り | 点線 | dotted |
| 8割ライン | 太めの破線 | mediumDashed |
| 方眼 | 細い破線 | hair または dashed |

## 4. 番号スタンプ（英字キー）— 自動判断はしない

複数セルを選択して押すと、**読む順** に番号を振る。

| キー | 振るもの | 縦書き既定 | 横書き既定 |
|---|---|---|---|
| D | 大問番号 | 一 二 三 … | 1 2 3 … |
| Q | 問番号 | 問一 問二 … | 問1 問2 … |
| P | 小問番号 | (1) (2) … ※縦中横は使わず「(1)」を1セルに入れる | (1) (2) … |
| M | 丸番号 | ① ② … | ① ② … |
| A | カナ | ア イ ウ … | ア イ ウ … |

- 押すと「開始番号 [1]」の小窓 → Enter で確定。続き番号は開始番号を変える
- 読む順：縦書き＝右の列から左へ、各列は上から下。横書き＝上から下、各行は左から右
- 大問をまたぐときは **大問ごとに選択して押す**（自動で区切らない）
- 選択は Shift+矢印（矩形）と Ctrl+クリック（飛び飛び）
- 振った番号は入力モードで書き換え可。番号スタイル（漢数字／算用数字／丸数字／括弧）は ⚙

## 5. モード（2つだけ。混同を起こさない）

> **キー割り当ては §17 で置き換えられている。** `T 太枠` は廃止。

```
🟦 置くモード（通常）  カーソル青枠。キーは全部「命令」。文字は絶対に入らない
   1〜7 欄 / D Q P M A 番号 / T 太枠 / Delete 消去 / 矢印 移動 / Shift+矢印 選択
   Ctrl+Z 戻す / Ctrl+Shift+Z・Ctrl+Y やり直す / Enter・F2・ダブルクリック → 入力モード

🟩 入力モード  カーソル緑枠、上部の帯も緑「入力中（Escで戻る）」
   小さな input が開き IME そのまま使える。Enter 確定 → 置くモードへ。Esc 取消 → 置くモードへ
   Enter/Esc 以外のショートカットは全部止まる（P も 1 も文字として入る）
```

実装上の必須事項：
- 置くモードでは **フォーカスされた input を存在させない**（IME が起動しないようにする）。判定は `e.code`（Digit1 等）で行い、`isComposing` 中は無視
- すべてのショートカットに `preventDefault`
- 置くモードで文字っぽいキーを押して何も起きなかったら、画面下に「文字を入れるには Enter」を一瞬表示
- F5 / Ctrl+R / タブを閉じる には `beforeunload` で「作業が消えます」確認
- 入力した文字は 1マス1文字で並ぶ（縦書きなら下方向）。欄の末尾に寄せる「から。」のような用途を想定
- モードは上部の帯（青／緑）とカーソル色の両方で常時表示
- ボタンにはキー名を印字（例「記号 [1]」「小問番号 [P]」「戻す [Ctrl+Z]」）
- 修飾キー付きショートカット（Alt+数字等）は HTML 版では採用しない（ブラウザと衝突）。exe 化後に任意追加

## 6. 画面構成（シンプル最優先）

> **この節は §17・§18 で置き換えられている。** 並びは「線の太さ → 欄を置く → 番号を振る → その他」。
> タブは 解答用紙／模範解答／描画 の3つ。欄の設定は Space（クリックはカーソル移動のみ）。

```
┌──────────────────────────────────────────────────────────────┐
│ ✏️ てすとも君　　　  [国語▼] タイトル[ … ]   🟦 置くモード     │
│  戻す[Ctrl+Z] やり直す[Ctrl+Y]   [Excel出力] [PDF(確認用)] [保存] ⚙ │
├───────────────────────┬──────────────────────────────────────┤
│ 欄を置く               │  プレビュー（A4 のマス目。印刷そのまま）  │
│ [1 記号][2 記号複][3 漢字]│  ─ カーソル／選択範囲を表示             │
│ [4 記述][5 答え][6 グラフ]│  ─ 置けない場所は赤く、理由を表示        │
│ [7 自由枠]              │  ─ 合計配点が100でなければ黄色く警告     │
│ 番号を振る              │                                      │
│ [D 大問][Q 問][P (1)]   │                                      │
│ [M ①][A ア]            │                                      │
│ [T 太枠][Del 消す]       │                                      │
│ タブ: (解答用紙 | 模範解答)│                                      │
└───────────────────────┴──────────────────────────────────────┘
```

- 起動画面：**「前回の続き」「教科テンプレから」「白紙から」** の3ボタン。テンプレは 国語／数学／英語／理科／社会 の定期テスト標準構成
- 前面に出すのは上図の要素だけ。番号スタイル・向き・観点欄・余白・氏名欄並び・マス寸法・バックアップ設定は ⚙ に格納
- 欄をクリック（または置くモードで Space）で、その欄の小窓：型／字数／配点／観点／完答／8割ライン／前置き・後置き文字
- ボタンには小さなマスの見本図を付ける

## 7. 模範解答

- 「模範解答」タブで小問ごとに答えを入力（同じ入力モード）
- 同じ枠の上に **1マス1文字** で載せる。記号・語句はマス中央、記述はマス目に沿って
- 枠の計算を解答用紙と共有するのでズレない
- 分数は字数自由の欄で上下に組む（§48）。√ は文字表現を使う
- Undo 履歴は解答用紙タブと分ける（混乱防止）

## 8. 出力

### 8.1 Excel（正本）
- 1ファイルに「解答用紙」「模範解答」の2シート
- 列幅・行高・印刷範囲・A4・向き・倍率80%・余白・中央配置・**「1ページに収める（縮小のみ）」** を埋め込む（安全弁）
- 罫線種は §3 の表どおり。文字はセル。図形なし。縦書きセルなし
- ファイル名：`解答用紙_国語_一年_2026-09-18.xlsx` の形式（学年は ⚙ の値をそのまま使う）
- 検収基準：Excel で開いて印刷プレビューが崩れない。お手本の印刷範囲と寸法が一致する

### 8.2 PDF（確認用）
- ブラウザ印刷。`@page` でサイズ・向き・余白を固定。印刷前に「ヘッダー/フッター OFF・倍率100%」の案内を出す
- 「正本は Excel」と画面に明記

### 8.3 作業ファイル(.json)
- 用紙設定＋欄・番号・文字・答え・配点のすべて。ファイル名 `国語_一年_2026-09-18.json` を自動命名
- ボタン名は「作業ファイルをダウンロード保存」。Edge/Chrome の File System Access API が使える場合は「上書き保存」に切り替える

### 8.4 自動バックアップ（localStorage）
- 1世代のみ。起動時「前回の続き」で復元
- **模範解答を含めない** を既定 ON（共用PC対策）。「終了時に消す」オプション
- 「このPCの一時保存は消えることがあります」と表示

## 9. データモデル（実装の指針）

```
Document
  paper: { subject, orientation, writing: 'vertical'|'horizontal', margins, title, nameLabel, showScoreBox, numberStyle }
  grid:  { cols, rows, colWidthExcel: 6.125, rowHeightPt: 13.5, scale: 80 }
  cells: Map<"c,r", { text?, font?, borders:{top,bottom,left,right: 'thin'|'medium'|'dotted'|'mediumDashed'|'hair'|null}, bold? }>
  fields: [ { id, type:1..7, rects:[{c,r,w,h}], chars?, exact?, points, aspect:'知技'|'思判表', complete?, prefix?, suffix?, number?, answer? } ]
  sections: [ { id, label, points, aspect, fieldIds:[] } ]
  answers: { fieldId: string }
history: Document のスナップショット配列（コマンドパターンより単純でバグが少ない）
```

- 画面描画も Excel 出力も **cells** から生成する（同じソース）。fields は編集用のメタ情報
- 配置判定：欄の矩形が用紙内かつ既存の欄と重ならないこと。違反なら置かず赤表示
- 合計配点：sections の points 合計。100 でなければ警告。観点別合計を得点枠に反映

## 13. 実装時の判断と、仕様との差分（v1.0 実装時に追記）

実装して動かした結果、仕様のままでは成立しなかった点と、その扱い。

### 13.1 仕様に足したもの（1つだけ）

**Shift+Space ＝ 離れたセルを選択に足す／外す**
§4 は飛び飛びの選択を「Ctrl+クリック」だけと書いているが、それではマウスが要る。
§1 の絶対条件「マウスなしキーボードだけで全操作が完結すること」を満たせないため、
Ctrl+クリックのキーボード版として追加した。新しい機能ではなく既存機能の操作手段。
Ctrl+Space は Windows の日本語入力の切替と衝突するため採用しない。

### 13.2 仕様と変えたもの

| 箇所 | 仕様 | 実装 | 理由 |
|---|---|---|---|
| §8.1 | 倍率80% と「1ページに収める」の両方を入れる | **倍率80%のみ**。印刷範囲を明示 | Excelでは両立せず、fitToPage を入れると倍率が無視されて約85%になり、受入条件2の「お手本と寸法が一致」を満たせなくなる。マス目はA4に収まるよう計算して作るので、1枚に収まることは設計で保証している |
| §3 | 方眼は5mm相当 | **約1cm方眼（1列×3行）** | マスの列幅が10.16mmで固定のため、5mmの縦線はセル罫線では引けない。中学校の作図で使う1cm方眼に寄せた |
| §9 | `sections`（大問）に配点と観点を持つ | **欄ごとに配点と観点**を持ち、合計はその積み上げ | 番号の採番を手動（§4）にしたため、欄を大問に束ねる情報が画面上に存在しない。利用者に見える動き（合計100の警告、観点別合計の反映）は仕様どおり |
| §1 | 依存は JSZip 程度（約100KB）まで同梱可 | **外部ライブラリなし**。ZIP（無圧縮）とOOXMLを自前で生成 | 必要なのは罫線・列幅・行高・文字・印刷設定・2シートだけで、約200行で足りる。読み込みが軽く、中身をすべて確認できる |

### 13.3 用紙のマス目（実装値）

余白から自動計算する。1文字マス = 1列 × 2行。

| 向き | 余白 | マス目 | 印刷範囲 |
|---|---|---|---|
| A4横（国語） | 8/9mm | 27列 × 50行 | 274.3 × 190.5 mm（可能領域 281 × 192） |
| A4縦（他教科） | 8/9mm | 19列 × 72行 | 193.0 × 274.3 mm（可能領域 194 × 279） |
| A4横 | 12mm | 26列 × 48行 | お手本 R6 と同じマス数 |

**幅10.16mm × 高さ7.62mm**で、お手本と完全に一致する。

### 13.4 ファイル名について

ブラウザでHTMLを直接開くと（file://）、blob や data のURLが別オリジン扱いになり、
ダウンロード時にファイル名が失われることがある。そのため保存は
**File System Access API の保存ダイアログを主経路**とし、使えない環境では
ダウンロードしたうえで、付けるべきファイル名を画面に出す。

## 14. 解答欄の並び（v1.1 で追加）

作成者の指摘により、お手本 R6 の列構造を調べ直して反映した。

### 14.1 お手本の構造（実測）

お手本の P列・Q列を上から追うと、**すべてのラベルが1行の枠つきセル**で、
解答欄の直前に置かれている。

```
P列                     Q列
行2  四     ← 大問番号   行2  三     ← 大問番号
行3  問一   ← 問番号     行3  (1)    ← 小番号
行4  ①     ← 小番号     行4〜11     解答欄（4文字分）
行5〜7      解答欄       行12 (2)
行8  ②                  行13〜20    解答欄
行9〜11     解答欄       行21 (3)
```

つまり **番号は解答欄の付属物**であり、同じ列の中に
「問番号 → 小番号 → 解答欄 → 小番号 → 解答欄 …」と積み上がる。

### 14.2 実装

- **欄は「番号欄」を必ず持つ**。カーソル位置が番号欄になり、解答欄はその次から始まる
  - 縦書き：番号欄は 1列 × 1行（解答欄の1行上）
  - 横書き：番号欄は 1列 × 2行（解答欄の1列左）
  - 番号欄には細罫線の枠を引く（お手本の `三マス君` `字数解答欄作成` と同じ）
- 欄を置いたあと、カーソルは**次の番号欄の位置**へ進む（欄と欄の間は空けない）
- **番号スタンプは番号欄を優先する**。選んだ範囲に番号欄が含まれていれば、
  そこだけに振る。列をまるごと選んで P を押すだけで (1)(2)(3)… が正しく入る。
  番号欄が無ければ、解答欄の中を避けて選択範囲に振る
- 番号欄以外のセルに番号を振ると、そのセルにも枠が付く（大問番号・問番号用）
- 番号欄の上にカーソルを置いて Space を押すと、その欄の設定が開く
- 教科テンプレは、問番号と小番号まで入った状態で始まる

### 14.3 前置き・後置き文字の置き場所

隣の欄とぶつかるため、**解答欄の内側**（先頭のマスと末尾のマス）に入れる。

```
(1) │ x＝            cm² │
```

答えのみ欄の既定の大きさを、これが収まるように広げた（横書き8文字分、縦書き4文字分）。
模範解答は前置き・後置きのマスを避けて入る。文字で埋まって答えの場所が残らないときは警告する。

### 14.4 字数指定の記述が分かれる列数

番号欄が1行使うため、A4横（50行）では1列あたり**24文字**になる。
50字は 17+17+16 の3列に均等分割される（1列25文字は51行必要で、A4に収まらない）。
分割数は「置いた位置から下に何文字入るか」で決まり、常に均等に割る。

## 15. 大問と問の並べ方（v1.2 で確定）

作成者の説明により、用語と並べ方を確定した。

### 15.1 用語

| 呼び方 | お手本での姿 | 場所 |
|---|---|---|
| **大問** | 太字の「一 二 三」 | お手本の2行目。各ブロックの先頭 |
| **問** | 「問一 問二」 | 大問の中 |
| **小問** | 「(1) (2)」「① ②」 | 問の中。解答欄の直前 |

「行」は縦書きの1本の書き並び、つまり **縦書きでは1列** を指す。

### 15.2 並べ方のきまり

1. **大問は行を分ける。** 新しい大問は次の行（縦書きなら左隣の列、横書きなら次の行）から始める。
   **大問と大問の間に空の行は作らない。**
2. **問・小問は行を開けず、すぐ下（横書きなら右）に続ける。** 欄と欄の間に空きマスを入れない。
3. **下に入らないときは、行を開けずに改行する。** 次の行の頭に置く。
   1つの大問が複数の行にまたがるときは、2行目以降もその大問の本文が始まる行位置に揃える。

### 15.3 実装

- 欄を置こうとして入り切らないときは、**自動で次の行の頭に置き直し**、その旨を画面に出す
- 欄を置いたあとのカーソルは、次の番号欄の位置（空きマスを挟まない）。
  下に1マスも残らなければ次の行の頭へ移る
- 教科テンプレは、大問ごとに行を分け、大問の先頭に **大問番号（一 二 三、太字14pt、枠つき）**、
  各解答欄の番号欄に **小問番号 (1)(2)(3)…** を入れた状態で始まる
- 問番号（問一）が要る大問では、番号欄の無い空きマスにカーソルを置いて `Q` を押すと、
  枠つきの問番号セルになる

### 15.4 お手本との照合（国語テンプレ）

```
22列（大問一）   21列（大問二）   20列（大問三）  19列・18列
 行1 一 [枠]      行1 二 [枠]      行1 三 [枠]     （記述の続き）
 行2 (1)[枠]      行2 (1)[枠]      行2 (1)[枠]
 行3-4 解答欄     行3-6 解答欄     行3〜 記述欄     行3〜 記述欄
 行5 (2)[枠]      行7 (2)[枠]                      ← 先頭行を揃える
 …                …
```

お手本の Q列（行2 三 → 行3 (1) → 行4〜11 解答欄 → 行12 (2)）と同じ構造。

## §24 追加仕様（v1.1）

### §24.1 解答欄の種類を7つに
| キー | 欄 | 備考 |
|---|---|---|
| 1 | シンプル枠 | 変更なし |
| 2 | 記号用 | 解答欄の大きさを **セル3つぶん**（1列×3行）に。Excelでは3行を結合し、答えは中央に入る |
| 3 | 語句 | 2〜5文字想定。**8割ラインは引かない**（`exact:true` 相当） |
| 4 | 記述 | 40字前後想定。8割ライン（以内／ちょうど）を選べる。旧「文字数」欄 |
| 5 | 長方形 | 旧 4 |
| 6 | グラフ | 旧 5 |
| 7 | 書き抜き | 「初め」1マス・○字・「終わり」1マス・○字 をひとつづきに並べる。○は同じ数。見出しのマスは結合し、模範解答は見出しを飛ばして文字マスに入る |

保存ファイルは `version:2`。`version` が 1 のファイルを開いたときは 3→4／4→5／5→6 に読み替える。

### §24.2 番号欄の連結
解答欄が複数の行（列）にまたがるとき、番号欄はその幅（高さ）いっぱいに広がり、左上のセルに `mg:{w,h}` を立てる。
画面では連結範囲の中央に文字を置き、Excel では `mergeCell` を出力する。外周の罫線は `unionBorders()` で左上のセルにまとめる。

### §24.3 セルの削除・移動
- `removeBand(alongRow, from, n, lo, hi, pullBefore)` … 帯を取り除いて詰める共通処理。帯にまるごと入った欄は消え、またがる欄は縮む。
- **K**：セルの削除（縦書き＝上詰め／横書き＝左詰め）
- **Shift+K**：行（列）ごと削除（縦書き＝右へ詰める・右端は固定／横書き＝上へ詰める）
- **Ctrl+X → Ctrl+V**：選んだ範囲にまるごと入っている欄・枠・文字を、カーソルの位置へ移動する。用紙の外やほかの欄に重なる場合は動かさない。

## §36 模範解答から解答欄を自動生成（v2.4）

- 起動画面の `btn-from-answers`、道具の `t-auto` から `openAnswerGenerator()` を開く。解析、編集一覧、生成確定の順。教科の既定を使い、国語は縦書き・A4横。同じ教科の既存用紙を作り直す場合はタイトル・氏名欄・向き・余白などの設定を保持する。
- `parseAutoAnswers()` はオフラインの明示的な書式解析。1行1問、大問見出し、問／小問番号、字数、8割ライン、完答、観点、配点を読む。全角数字対応。括弧内は指定をすべて読み取れた場合だけ除去し、答えの部分一致で語を消さない。
- 答え1文字→記号、8文字以内で句点なし→語句、それ以外→記述を仮判定。明示指定を優先。指定のない観点は欄の種類から仮設定、配点は0。推定・未指定を一覧に表示し、採点情報の確定と区別する。
- 種類は既存の欄データを利用：記号=2、字数自由の語句・記述・欄のみ=6、字数指定=5、グラフ=7、漢字=8、初終=3。`fixedChars` で字数を維持する欄と連続文字として配置する欄を区別する。
- `buildAutoDocument()` は現在の `doc` と履歴に触れず候補用紙を作る。同じ大問を最初の出現順で集め、問を連続配置し、必要なときだけ次の列／行へ折り返す。大問見出しはその大問の幅にそろえる。国語の漢字欄は1.3倍に広げ、左端の空き列だけを減らしてA4幅を維持する。
- 全問が収まり、模範解答が表示できることを検証した後に確定する。範囲外・不正な値・字数不足の場合は一覧に理由を表示し、元の用紙・履歴・ID採番を保つ。一部だけ生成して問題を欠落させない。
- 生成欄の `auto` に大問・欄の種類など再編集用の指定を保存する。答えは従来の `doc.answers` だけに保存するため、模範解答を一時保存しない設定を維持できる。保存形式はversion:4の追加属性とし、既存ファイルを継続して読み込める。
- 生成した欄は既存の移動・書式・採点・入力操作で編集できる。全欄が自動生成欄の場合は一覧から追加・削除・種類変更・再配置もできる。現在の答え・採点・文字サイズ・色・線・注記を取り込む。再配置は明示的なチェックを必要とし、手動の位置・描画は置換する。
- 用紙の置換は解答用紙の履歴に全ドキュメントを一度に記録する。戻す／やり直しで答え・描画も含めて復元し、別の用紙に対する模範解答・描画タブの履歴を無効化する。復元時は欄IDの重複を避けるため採番を再確認する。
- 入力上限は5万文字・200問。欄に入りきらない場合は用紙を分ける。任意の問題文から採点基準を断定する機能や、Excelの読み込み・グラフの作図自動生成は含まない。

## §37 字数自由の模範解答の配置（v2.4）

- `flowingAnswerPlan()` が、字数自由の欄・枠の答えを連続文字列として配置する。縦書きの日本語は縦方向に連ね、横書き・英数字は行の幅で折り返す。注記のあるセルを避ける。
- 指定した文字サイズを上限に、0.5pt刻みで6ptまで調整する。6pt未満を利用者が明示指定した場合はその値を維持する。Canvasの文字幅と余白、実際の列幅と行高を使って収まりを検査する。
- 字数指定・漢字・初終の欄は文字マスと指定字数を維持し、1文字1マスで配置する。入りきらない場合は答えのデータを保持し、点検対象にする。初終はそれぞれの区画の字数超過を検査する。
- SVGとExcelは同じ `answerPlan()` の結果を使う。連続する文字列は必要なセル範囲を結合し、縦方向の文字列はExcelの `textRotation=255`、画面では字ごとのtspanで同じサイズ・順に表示する。
- `node tools/test-answer-generator.cjs` で実ブラウザ検証。Playwright・Chromium・Pythonのopenpyxlが必要。ブラウザが今回の実行で出力したExcelを `tools/check-answer-generator-xlsx.py` で検査し、2シート、全答え、配点、罫線、8割ライン、文字サイズ、A4設定、結合の重複を確認する。


## §38 自動生成の省略入力・番号登録・共通設定（v2.5）

- 答えだけの入力を基本にする。大問・問番号・配点・観点・種類はプルダウン、完答・8割ラインはチェック。字数・幅・高さは該当する種類だけに表示する。配点・問番号の自由入力も保持する。
- 画面の共通設定を `parseAutoAnswers(source, defaults)` に渡し、明示指定がない項目を補う。明示した貼り付けの指定を優先する。「自動判別」は答えの編集後も再評価する。未指定・推定と確定した設定を区別する。
- 空行による大問分けは任意のチェック。連続・先頭・末尾の空行で空の大問を生成しない。大問ごとに選んだ問番号書式・開始番号で採番する。見出しの明示指定も継続して読める。
- 問番号書式は既存のSTAMPSを使い、問一／(1)／①／ア／数字／なし。大問は漢数字／数字。「次の大問を登録」は未使用の次の番号を登録して追加先に設定し、独自の表示名も登録できる。
- 全問・大問ごと・チェックした問題に、共通設定の一括適用、連番の振り直し、大問の変更ができる。チェックすると自動でその問題だけを変更対象にする。各問題の個別設定も保つ。
- 「この設定を覚える」で `options.autoInput` に大問の登録・番号書式・共通設定を保存する。従来のブラウザ設定と同じlocalStorageを使い、答え本文は保存しない。作業ファイルの欄データ・模範解答データは従来どおり。
- 配置は既存の自動生成処理を継続使用し、番号枠を含めた領域を検査する。下に収まらなければ左の列へ、横書きでは次の行へ折り返し、大問と問番号の続きを維持する。用紙全体に入らないときは確定を止める。


## §39 入力形式・配置・編集窓の整理（v2.6、§36〜38のUIを更新）

- 数字だけの行を大問番号として読み、問題の行は `問番号，模範解答，点数，観点`。第一項目の数字を「問一」等へ変換し、直後の（1）や（A）を小問として付ける。ASCII／全角カンマ／読点を混在できる。観点の知・思、裸の配点数字にも対応する。
- 引用したフィールド内の区切り・改行・引用符を保持する。答えは独立した項目として読み、「知」「完答」等の答えを採点指定と誤認しない。任意の番号は引用した第一項目として保持し、画面と入力文字列を往復できる。従来の空白区切り入力も継続する。
- 「次の大問を登録」「この設定を覚える」と共通の種類設定を削除。旧 `options.autoInput` の隠れた設定は使わない。種類のプルダウンには実際の判別結果を表示し、自動判別という選択肢を設けない。手動で種類を変えた後はその種類を維持する。
- 一括変更を配点・観点に限定。全問・大問ごと・チェックした問題を対象に、配点だけ／観点だけ／両方を変更できる。「変更しない」は現在値を保持する。チェックの用途をカードと一括変更欄に明記し、生成対象は全問とする。
- 国語で候補欄の横幅が複数列になり、現在の位置が列の途中なら、新しい未使用列の先頭へ移してから寸法を再計算する。大問見出しの直下へ揃え、重なり・A4範囲外を検査する。
- 画面上部に常時表示する「模範解答の編集」を追加し、描画タブからも編集窓を開ける。現在の欄を入力一覧・入力文字列へ復元する。手動で追加した通常欄や従来の保存ファイルの欄も一覧に含め、種類・寸法・採点・書式を取り込む。カスタムA/Bは従来の登録寸法を使う。
- 一覧編集・追加・削除・一括変更を入力文字列にも同期する。未読の文字列変更があるときは、一覧の変更・生成を先に進めず再解析を案内する。再解析で同じ大問・問番号の欄の書式を引き継ぐ。再生成は従来の全体履歴で戻せる。
- 日本語の階層番号が小さくなり過ぎないよう、番号文字列の測定幅に合わせてサイズを決める。検証に指定形式、（A）、引用、一覧との往復、複数列の先頭配置、個別の一括採点、全タブからの再編集、手動追加欄の再編集を追加。

## §40 大問の余白・中央配置・小問の個別選択（v2.7）

- 自動生成で大問が変わるとき、縦書きは使用済み最左列の隣を1列空け、その次の列の先頭へ移る。横書きは使用済み最下行の次に1文字行（`CHAR_ROWS`）を空ける。同じ大問内の折り返しは連続配置を維持する。空白を含めてA4容量を検査し、入りきらなければ現在の用紙を保つ。
- 大問見出しに `centerAcross:true` を保存する。奇数の幅では中央のセル、偶数では中央の2セルを結合して番号を中央へ置く。横書きでは1文字行の高さも結合する。共通の `buildCells()` を通すため、画面・解答用紙・模範解答・Excelが一致する。従来の手動番号データは維持する。
- 同じ問の小問は `1,(1),ア,2,知` と `1,(2),イ,2,知` のように、同じ問番号を使った別の行で入力する。各小問の解答欄・配点・観点は独立し、完答も既存の欄ごとの指定を使う。
- 一覧の問番号と小問番号を別のプルダウンに分ける。小問なし、数字1〜20、英字A〜Z、自由指定に対応し、入力済みの全角括弧や独自の小問番号も選択肢へ含める。変更しない側の番号を保ち、既存の `row.label` へ結合して入力文字列に同期する。保存形式を分岐させない。
- 「1問追加」の続き番号は小問の括弧を除いた問番号から決め、問一(1)・問一(2)があれば通常の次の問は問二とする。
- 回帰検証に縦横の空白、2列／3列見出しの中央位置、小問番号の変更と解除・自由指定・保存再読込、通常問題の追加を追加。今回出力した4組のExcelと作業ファイルから、独立したopenpyxl検査で大問の中央セル・結合・空白列／行・問番号も確認する。

## §41 見本に合わせた問・小問のセル分離と欄のみの初期寸法（v2.8）

- `問一(1)`・`問一(2)`は、縦書きでは親問番号1セル→小問番号1セル→解答欄→次の小問番号1セル→解答欄の順に配置する。小問番号は既存の `field.label` に置き、親問番号は既存の1セルの枠（`decorations`、`questionHeading:true`）と `texts` を使う。横書きは同じ順で右へ並べる。複数列の解答欄でも親問・小問番号は各1セルとする。
- 連続する同じ親問では番号セルを共有し、`field.auto.questionId` から親枠のIDを参照する。親問・大問が変わったときと折り返した先の列／行では、新たな親問番号を置く。候補配置に親問セルも含めてA4容量と重なりを検査する。親問セルだけを先に確定しない。
- 親問枠は既存の移動・行列挿入・削除・保存・Undoの処理に乗せる。列幅調整で左端を詰める際も同時に移動する。再編集は親枠の現在の文字と小問番号を結合し、以前の番号一体型のファイルも従来どおり読み込む。
- 親問・小問番号をEnterで直接編集するときは番号セル内に文字列を保持する。親問番号の変更は、その枠を共有する小問の再編集にも反映する。配点・観点・完答は小問ごとの既存設定を維持する。
- 自動生成の「解答欄のみ」は、幅1・高さ10文字マスを標準とする。解析時と種類の選択時に初期値を実際の幅・高さ欄へ表示し、0（自動）は標準へ補う。指定済みの正の寸法は優先し、作成済みの欄の個別寸法も維持する。他の種類の寸法は変更しない。
- 検証を親問共有・折り返し・大問変更・別セル配置・直接編集・再編集と欄のみの初期値に拡張。5組のブラウザ出力Excelをopenpyxlで検査し、親問と小問のセルも独立に確認する。

- 大問間は縦書きで列幅100→80→60→40％、横書きで1文字行→半行。全境界を同じ幅とし、空白はなくさない。空白の最小幅でも足りない場合、欄幅を97.5％から2.5％刻みで80％まで縮め、最初に収まった候補を採用する。
- 縦書きの右側6列（得点枠なしは2列）は通常幅を保ち、漢字欄の1.3倍の比率、各欄の高さ・マス数・問番号・小問・配点・観点・模範解答を維持する。最終幅で模範解答が欠けないか再検査する。
- 既存の列幅配列colwと列数で寸法を表現する。任意のpaper.autoFitに作成時の空白・欄幅の割合を保存し、画面下部と完了メッセージに表示する。保存形式4は維持する。読み込みと同じ用紙の設定変更では、A4幅に収まる保存済み列数・列幅を復元する。
- すべての候補が失敗した場合、問題を分ける案内を出し、現在のドキュメント・採番・履歴に触れない。再生成で通常寸法に戻る場合は調整情報を除去し、戻す／やり直すでは寸法と調整情報も復元する。
- tools/test-auto-fit.cjsで空白のみ・空白と欄幅・大問1つ・漢字・横書きの配置、全問保持と衝突、保存復元、設定、再生成、失敗時の原子性、履歴、Excelの列幅と内容を検証する。

## §48 ショートカットの明示・関数グラフ・分数（v2.15）

- 欄作成ボタンの名前の先頭に①〜⑨・⓪を表示し、aria-keyshortcutsと説明にも数字キーを示す。fieldOrderの並び替えを反映し、⓪は0キーと案内する。
- 模範解答のy=で始まる式をグラフとして推定する。式から描く窓を、一覧のグラフ行・模範解答タブのボタン・グラフ欄のEnterから開く。一次・反比例・二次の入力例、最大4式、x/yの最小・最大値、プレビュー、入力検証、キャンセル・フォーカス循環に対応する。
- 式は数値、x、四則演算、暗黙の乗算、括弧、累乗を構文解析する。JavaScriptを実行せず、長さ・深さ・トークン数を制限する。全角文字、×÷、²³に対応する。表示範囲の初期値は各軸−5〜5、最小値と最大値の大小・有限性を検証し、数値入力では分数も受け付ける。
- 曲線を細分して表示範囲へクリップし、分母0と不連続点をまたぐ線を除く。軸・目盛りは解答用紙と共有し、曲線と式は模範解答だけに載せる。式と範囲の編集は既存欄の寸法・配点等を変更しない。
- 生の式は従来どおりanswersに保持し、任意のanswerGraphsに欄IDごとの表示範囲を保存する。答えの履歴・保存復元・一時保存の除外に対応し、currentAutoRows経由で再生成へ引き継ぐ。複数の式は一覧入力の1行ではセミコロンで区切り、保存時に改行へ戻す。保存形式4は維持する。
- 数値・xや括弧の分子/分母を共通の分数トークンに分け、グラフの式と字数自由の模範解答で分子・横線・分母へ組む。書き込み文字を避け、欄に収まるサイズまで調節する。字数指定・漢字・初終は既存のマス数と入力を維持する。

## 教科別の横書き解答欄（参考用紙への対応）

添付の「My探究」に含まれるWordの表寸法・模範解答とExcelのセル／結合範囲を参考に、数学・英語・理科・社会の初期値を分ける。数学の計算・途中式、英語の単語／英文、理科の語句／化学式／単位、社会の用語／説明文を区別する。参考資料をそのまま複製する機能ではなく、A4・1枚で手書きしやすい初期配置へ反映する。

- 国語の基本セル、縦書き、初終、漢字、字数指定、見本は従来どおり。保存済みの用紙を開くだけでは寸法を変えない。
- 基本セルは幅10.16mm・高さ3.81mmを維持。以下の「高さ1」は2行分＝7.62mm。横書きの4教科では解答欄を複数セルの長方形で作り、明示的な字数指定がある場合だけ文字マスにする。

| 教科 | 短答の最小幅×高さ | 自由記述の幅×最小高さ | 空欄のみの既定 |
|---|---|---|---|
| 数学 | 4×2（約40.6×15.2mm） | 12×4 | 6×3 |
| 英語 | 4×2（約40.6×15.2mm） | 12×2 | 8×2 |
| 理科 | 4×1（約40.6×7.6mm） | 12×2 | 6×2 |
| 社会 | 4×1（約40.6×7.6mm） | 12×3 | 8×2 |

答えの長さ・改行により幅や高さを増やす。数式・化学式は高さ2以上、途中式・説明は高さ4以上。「幅」「高さ」を個別に指定した場合は指定値を優先する。A4超過時の調整・原子的な失敗・欠落検査は既存の仕組みを使う。

自動生成に「数式・数値・化学式」「英文」「途中式・説明」を追加。数式等は既存の長方形型を使い、明示した種類は推定で上書きしない。数学の数値や理科の化学式を1文字の記号欄と誤認しない。4教科の波線（例：5～10）は初終として推定しない。国語以外で初終が必要な場合は明示指定する。

英語の模範解答は空白、大文字・小文字、句読点を保持し、行末に収まらない単語は次行へ送る（欄幅より長い単語は文字単位で折り返す）。`and/or` のような斜線を分数にしない。英語でも「数式」を明示すれば分数表示が使える。理科の添字は入力文字（H₂O等）をそのまま保持し、化学式や単位を勝手に補正しない。

教科選択に応じた入力例・案内と、同じ配置処理による空の見本を提供する。見本には模範解答を隠して保存しない。新しい種類と寸法は作業ファイル・一覧再編集・Excelに引き継ぐ。

検証：`node tools/test-subject-layouts.cjs`。4教科の画面操作、寸法、範囲外・重複、保存／読込、再生成、英文折り返し、スマートフォン幅、ExcelのA4設定・結合・模範解答を検査する。既存4スイートも継続する。

## 模範解答を詰めすぎない表示

字数自由の模範解答は、内側余白を差し引いた領域の92%を折り返し・収容判定に使う。横書きの複数列の欄は、Excelのインデント1（スペース3個相当）を設定し、画面も同じ文字幅の見積もりで開始位置を内側に移す。余白は模範解答にだけ付け、タイトル・問番号・注記・空の解答用紙には付けない。1列の記号欄は中央配置、字数固定の欄は従来の1文字ずつの中央配置を維持する。

縦書きの字数自由の欄は、6行以上の連続領域では上下各1行を文字の結合範囲から除外し、画面とExcelの両方で書き始め・書き終わりに空きセルを残す。短い領域では文字列を上下中央に配置する。収容判定にも余裕を設け、字数固定の欄の寸法は変更しない。分数の描画は左右最大1.5mm・上下1mmの余白と右端8%の予備領域を設け、画面とExcelの描画に同じ座標を使う。文字縮小や不足判定でも余白を撤去しない。

`node tools/test-answer-padding.cjs` でSVGの開始位置、短い記号の中央配置、長文の折り返しと欠落防止、数式の余白、Excelのインデントと空欄への非適用を検証する。


## 初めて使う方向けの取説

「その他 → 使い方」は「かんたんガイド」「入力の書き方」「詳しい機能」の3タブ。初期表示はかんたんガイドとし、模範解答から作成・確認・Excel出力・作業保存に絞る。入力形式は4項目の説明と実用例、大問行、引用、省略時の注意を示す。小問・字数・教科別の指定と手動操作は詳しい機能に分離。入力窓の「書き方ガイド」は入力形式タブを開き、閉じると入力内容を保ったまま元のボタンへ戻る。タブは左右キー、閉じる操作はEscと閉じるボタンに対応。docs/USAGE.mdは基本編、docs/USAGE-DETAILS.mdに既存の詳しい説明を保持。


## 図解ガイドと使い方の入口

使い方ボタンを「その他」から独立させ、トップ画面にも追加。トップには模範解答・見本・白紙の各モードの短い説明を表示する。生成画面の上部には入力→確認→完成の案内と「このモードの使い方」を常時表示し、入力欄の直前にも色付きの4項目図を表示する。取説はモードの比較、数字キー→欄の図、入力と完成イメージの対比を中心にし、細かな説明は折りたたむ。左の欄ボタンに現在の数字キーをキートップとして表示。並べ替え後のキーも図解に反映する。図解はHTML/SVGで同梱しオフライン・画面幅の変化に対応する。


## 入力ガイドの色分け

入力例・説明・完成イメージの同じ項目を同じ色で表示します。青＝大問（数字だけの行）、緑＝問題番号、茶＝答え、紫＝点数、桃＝観点。色名と項目名も併記するため、色だけで判断する必要はありません。入力画面の書き方図も同じ配色です。入力例はそのままコピーして使えます。色は説明用の目印で、用紙の印刷色は変わりません。
