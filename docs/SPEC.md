# てすとも君（解答用紙メーカー）仕様書（v1.0 確定版）

作成者と担当AIの対話で確定した仕様。実装者はこの文書を唯一の仕様として扱うこと。
不明点があればここに追記して合意を取る。仕様にない機能は追加しない（「機能もりもりより一目瞭然」が最優先）。

---

## 0. 一言でいうと

中学校（高校でも使う）の教師が、定期テストの **解答用紙と模範解答を、キーボードだけで3〜5分で作る** ツール。
ブラウザで開く **単一HTMLファイル**。オフライン・通信ゼロ。出力は **Excel(.xlsx) が正本**、PDFは確認用。

作成者が自作していた「マクロ付き国語解答用紙Excel」（`docs/reference/` 参照）が完成形のお手本。
その **印刷範囲（B1:AA48）をそのまま再現できる** ことが到達点。

## 1. 形式・制約（絶対条件）

| 項目 | 決定 |
|---|---|
| 配布形態 | `answer-sheet-maker.html` 1ファイル。ダブルクリックで開く。将来 exe に包める構造にする |
| 通信 | ゼロ。fetch/XHR/外部CDN/外部フォント/画像URL いずれも禁止。ライブラリは同梱 |
| 依存 | 圧縮（JSZip 程度、約100KB）のみ同梱可。xlsx は OOXML を自前生成（SheetJS 無償版は罫線・印刷設定が出せない、ExcelJS は重い） |
| 用紙 | 必ず **A4・1枚**。縮小しない。収まらないときは置けない＋警告 |
| 余白 | 既定は作成者Excelの実績値（左右 8mm、上下 9mm）。⚙で 10mm / 12mm を選択可 |
| 図形禁止 | マス・番号・答え・得点枠はすべて **セル罫線とセル文字**。テキストボックス等の図形は使わない（出力後にExcelで手直しできるようにするため） |
| 縦書きセル禁止 | Excel の縦書き（textRotation=255）は長音・句読点・拗促音が崩れる。**1マス1文字** で縦に並べる。タイトルと氏名欄も同様 |
| フォント | ワークブック標準フォントを固定（游ゴシック 11。無ければ MS ゴシック）。画面は system-ui |
| 保存先 | 作業ファイル(.json)はユーザーのPCにダウンロード保存。自動バックアップは localStorage（後述の機密配慮あり） |
| 対象環境 | Windows の Edge/Chrome。マウスなしキーボードだけで全操作が完結すること |

## 2. 用紙とマス目（お手本Excelの実測値）

### 2.1 お手本の実測値

- 印刷範囲 `B1:AA48`、A4 横、印刷倍率 80%、印刷位置 水平・垂直とも中央
- 列幅（Excel単位）：B=3.25、C〜N=6.125（12列）、O=2.375（区切り）、P〜R=6.125、S〜V=7.375、W〜Y=6.5、Z=5.75（氏名欄）、AA=9（タイトル）
- 行高：1行目 12.95pt、2〜48行目 13.5pt
- **1文字 = 2行（13.5pt×2）**、番号ラベル（問一・(1)・①）は 1行
- 80%印刷後の実寸：1文字マス ≒ **幅10.2mm × 高さ7.6mm**、番号行 ≒ 3.8mm
- 右端：`Z2:Z47` 結合＝氏名欄（16pt）「一年　　組　　番　氏名（　　　　）」、`AA2:AA43` 結合＝タイトル（18pt）「第１学年　学年末テスト　解答用紙」
- 2行目：大問番号「八 七 六 五 四 三 二 一」（14pt、各ブロックの先頭列）
- 3行目：小問ラベル「問一」「(1)」「①」（11〜14pt）
- 左下 `W29:Y47` 付近：得点枠「合計 100 / 思・判・表 50 / 知・技 50」（お手本では図形。**本ツールではセルで再現**）
- 記述欄末尾の固定文字例：`H37:H46` に「から。」（縦書き）

### 2.2 本ツールのマス目

お手本の値をそのまま採用する（実績があり、印刷で寸法が保証されているため）。

| 教科 | 用紙 | 文字方向 | 大問の並び | 列幅 / 行高 | 印刷倍率 |
|---|---|---|---|---|---|
| 国語 | A4 横 | 縦書き | 右 → 左（問一が右端） | 6.125 / 13.5pt | 80% |
| 数学・英語・理科・社会・その他 | A4 縦 | 横書き | 上 → 下、左 → 右 | 6.125 / 13.5pt | 80% |

- 画面のマス目 = Excel のセル。**1文字マス = 縦2セル**（縦書き）／横書きも 1文字 = 幅1列 × 高さ2行 で統一
- 最小マス 8mm。これより小さくしない
- 縦書き用紙の収容量：欄用の列 約24列（氏名・タイトル・余白を除く）、行 48
- 教科・向き・文字方向・番号スタイルは ⚙ で後から変更可（高校・社会の縦書き等）

### 2.3 新規作成時に自動配置するもの

- タイトル（教科・学年・テスト名から生成。例「第１学年　２学期中間テスト　解答用紙」）
- 氏名欄（既定「一年　　組　　番　氏名（　　　　　　）」。並び順は ⚙：年組番氏名／組番氏名）
- 得点枠：合計 / 知・技 / 思・判・表（各セル）。位置は縦書き＝左下、横書き＝右上。⚙で ON/OFF
- 配置場所はお手本と同じ（縦書き：右端2列にタイトル・氏名）

## 3. 欄の型（数字キー 1〜7）

> **この節は §17.1 で置き換えられている。** 欄は 1〜5 の5種類。`T` キーも廃止（線の太さは Shift+1 / Shift+2）。
> 以下は v1.0 時点の記述として残す。

| キー | 型 | 形 | 作成時に聞くこと |
|---|---|---|---|
| 1 | 記号（一文字） | 1文字マス 1つ | なし |
| 2 | 記号（複数） | 1文字マスを n 個縦（横書きなら横）に連結 | 個数 |
| 3 | 漢字・語句 | 1文字マス n 個、区切りは点線、外枠実線 | マス数（既定 2） |
| 4 | 記述（字数指定） | 1文字マス n 個。「以内」なら **8割ライン** | 字数、以内／ちょうど（既定 以内） |
| 5 | 答えのみ | 横長の1欄（縦書きでは縦長）。前置き・後置き文字可（「x＝」「cm²」） | 欄数（既定 1）。前置き・後置きは後から入力モードで |
| 6 | グラフ・作図 | 白枠 / 方眼（5mm 相当。方眼線は細い破線） | 白枠／方眼、大きさ（列数×行数） |
| 7 | 自由記述枠 | 罫線なしの大枠（途中式・証明） | 高さ（行数） |

共通：
- 欄は **矩形の集合**（記述が複数列に分割されるため）。番号は欄に1つ
- 記述の字数が列の残りに収まらないときは自動で複数列に分割（例：50字 → 25字×2列）。8割ラインは全字数の8割位置を列に換算して引く（50字なら40字目＝2列目の15字目）
- 作成後、カーソルは「次の位置」（縦書きなら同じ列の下、列が尽きたら左の列の上）へ自動移動
- 小問ごとに **配点**（既定＝大問配点÷小問数）と **観点**（知技／思判表、既定は大問の観点）
- T：選択範囲の外枠を太線（完答）。Delete：選択範囲の罫線と文字を消す

罫線の種類は3段階に固定し、Excel罫線にそのまま対応させる：

| 用途 | 線 | Excel |
|---|---|---|
| マス罫線・欄の外枠 | 細実線 | thin |
| 完答・大問の外枠 | 中太実線 | medium |
| 文字区切り | 点線 | dotted |
| 8割ライン | 太めの破線 | mediumDashed |
| 方眼 | 細い破線 | hair または dashed |

## 4. 番号スタンプ（英字キー）— 自動判断はしない

複数セルを選択して押すと、**読む順** に番号を振る。

| キー | 振るもの | 縦書き既定 | 横書き既定 |
|---|---|---|---|
| D | 大問番号 | 一 二 三 … | 1 2 3 … |
| Q | 問番号 | 問一 問二 … | 問1 問2 … |
| P | 小問番号 | (1) (2) … ※縦中横は使わず「(1)」を1セルに入れる | (1) (2) … |
| M | 丸番号 | ① ② … | ① ② … |
| A | カナ | ア イ ウ … | ア イ ウ … |

- 押すと「開始番号 [1]」の小窓 → Enter で確定。続き番号は開始番号を変える
- 読む順：縦書き＝右の列から左へ、各列は上から下。横書き＝上から下、各行は左から右
- 大問をまたぐときは **大問ごとに選択して押す**（自動で区切らない）
- 選択は Shift+矢印（矩形）と Ctrl+クリック（飛び飛び）
- 振った番号は入力モードで書き換え可。番号スタイル（漢数字／算用数字／丸数字／括弧）は ⚙

## 5. モード（2つだけ。混同を起こさない）

> **キー割り当ては §17 で置き換えられている。** `T 太枠` は廃止。

```
🟦 置くモード（通常）  カーソル青枠。キーは全部「命令」。文字は絶対に入らない
   1〜7 欄 / D Q P M A 番号 / T 太枠 / Delete 消去 / 矢印 移動 / Shift+矢印 選択
   Ctrl+Z 戻す / Ctrl+Shift+Z・Ctrl+Y やり直す / Enter・F2・ダブルクリック → 入力モード

🟩 入力モード  カーソル緑枠、上部の帯も緑「入力中（Escで戻る）」
   小さな input が開き IME そのまま使える。Enter 確定 → 置くモードへ。Esc 取消 → 置くモードへ
   Enter/Esc 以外のショートカットは全部止まる（P も 1 も文字として入る）
```

実装上の必須事項：
- 置くモードでは **フォーカスされた input を存在させない**（IME が起動しないようにする）。判定は `e.code`（Digit1 等）で行い、`isComposing` 中は無視
- すべてのショートカットに `preventDefault`
- 置くモードで文字っぽいキーを押して何も起きなかったら、画面下に「文字を入れるには Enter」を一瞬表示
- F5 / Ctrl+R / タブを閉じる には `beforeunload` で「作業が消えます」確認
- 入力した文字は 1マス1文字で並ぶ（縦書きなら下方向）。欄の末尾に寄せる「から。」のような用途を想定
- モードは上部の帯（青／緑）とカーソル色の両方で常時表示
- ボタンにはキー名を印字（例「記号 [1]」「小問番号 [P]」「戻す [Ctrl+Z]」）
- 修飾キー付きショートカット（Alt+数字等）は HTML 版では採用しない（ブラウザと衝突）。exe 化後に任意追加

## 6. 画面構成（シンプル最優先）

> **この節は §17・§18 で置き換えられている。** 並びは「線の太さ → 欄を置く → 番号を振る → その他」。
> タブは 解答用紙／模範解答／描画 の3つ。欄の設定は Space（クリックはカーソル移動のみ）。

```
┌──────────────────────────────────────────────────────────────┐
│ ✏️ てすとも君　　　  [国語▼] タイトル[ … ]   🟦 置くモード     │
│  戻す[Ctrl+Z] やり直す[Ctrl+Y]   [Excel出力] [PDF(確認用)] [保存] ⚙ │
├───────────────────────┬──────────────────────────────────────┤
│ 欄を置く               │  プレビュー（A4 のマス目。印刷そのまま）  │
│ [1 記号][2 記号複][3 漢字]│  ─ カーソル／選択範囲を表示             │
│ [4 記述][5 答え][6 グラフ]│  ─ 置けない場所は赤く、理由を表示        │
│ [7 自由枠]              │  ─ 合計配点が100でなければ黄色く警告     │
│ 番号を振る              │                                      │
│ [D 大問][Q 問][P (1)]   │                                      │
│ [M ①][A ア]            │                                      │
│ [T 太枠][Del 消す]       │                                      │
│ タブ: (解答用紙 | 模範解答)│                                      │
└───────────────────────┴──────────────────────────────────────┘
```

- 起動画面：**「前回の続き」「教科テンプレから」「白紙から」** の3ボタン。テンプレは 国語／数学／英語／理科／社会 の定期テスト標準構成
- 前面に出すのは上図の要素だけ。番号スタイル・向き・観点欄・余白・氏名欄並び・マス寸法・バックアップ設定は ⚙ に格納
- 欄をクリック（または置くモードで Space）で、その欄の小窓：型／字数／配点／観点／完答／8割ライン／前置き・後置き文字
- ボタンには小さなマスの見本図を付ける

## 7. 模範解答

- 「模範解答」タブで小問ごとに答えを入力（同じ入力モード）
- 同じ枠の上に **1マス1文字** で載せる。記号・語句はマス中央、記述はマス目に沿って
- 枠の計算を解答用紙と共有するのでズレない
- 分数・√ は文字表現（「2/3」「3√2/2」）で割り切る
- Undo 履歴は解答用紙タブと分ける（混乱防止）

## 8. 出力

### 8.1 Excel（正本）
- 1ファイルに「解答用紙」「模範解答」の2シート
- 列幅・行高・印刷範囲・A4・向き・倍率80%・余白・中央配置・**「1ページに収める（縮小のみ）」** を埋め込む（安全弁）
- 罫線種は §3 の表どおり。文字はセル。図形なし。縦書きセルなし
- ファイル名：`解答用紙_国語_一年_2026-09-18.xlsx` の形式（学年は ⚙ の値をそのまま使う）
- 検収基準：Excel で開いて印刷プレビューが崩れない。お手本の印刷範囲と寸法が一致する

### 8.2 PDF（確認用）
- ブラウザ印刷。`@page` でサイズ・向き・余白を固定。印刷前に「ヘッダー/フッター OFF・倍率100%」の案内を出す
- 「正本は Excel」と画面に明記

### 8.3 作業ファイル(.json)
- 用紙設定＋欄・番号・文字・答え・配点のすべて。ファイル名 `国語_一年_2026-09-18.json` を自動命名
- ボタン名は「作業ファイルをダウンロード保存」。Edge/Chrome の File System Access API が使える場合は「上書き保存」に切り替える

### 8.4 自動バックアップ（localStorage）
- 1世代のみ。起動時「前回の続き」で復元
- **模範解答を含めない** を既定 ON（共用PC対策）。「終了時に消す」オプション
- 「このPCの一時保存は消えることがあります」と表示

## 9. データモデル（実装の指針）

```
Document
  paper: { subject, orientation, writing: 'vertical'|'horizontal', margins, title, nameLabel, showScoreBox, numberStyle }
  grid:  { cols, rows, colWidthExcel: 6.125, rowHeightPt: 13.5, scale: 80 }
  cells: Map<"c,r", { text?, font?, borders:{top,bottom,left,right: 'thin'|'medium'|'dotted'|'mediumDashed'|'hair'|null}, bold? }>
  fields: [ { id, type:1..7, rects:[{c,r,w,h}], chars?, exact?, points, aspect:'知技'|'思判表', complete?, prefix?, suffix?, number?, answer? } ]
  sections: [ { id, label, points, aspect, fieldIds:[] } ]
  answers: { fieldId: string }
history: Document のスナップショット配列（コマンドパターンより単純でバグが少ない）
```

- 画面描画も Excel 出力も **cells** から生成する（同じソース）。fields は編集用のメタ情報
- 配置判定：欄の矩形が用紙内かつ既存の欄と重ならないこと。違反なら置かず赤表示
- 合計配点：sections の points 合計。100 でなければ警告。観点別合計を得点枠に反映

## 13. 実装時の判断と、仕様との差分（v1.0 実装時に追記）

実装して動かした結果、仕様のままでは成立しなかった点と、その扱い。

### 13.1 仕様に足したもの（1つだけ）

**Shift+Space ＝ 離れたセルを選択に足す／外す**
§4 は飛び飛びの選択を「Ctrl+クリック」だけと書いているが、それではマウスが要る。
§1 の絶対条件「マウスなしキーボードだけで全操作が完結すること」を満たせないため、
Ctrl+クリックのキーボード版として追加した。新しい機能ではなく既存機能の操作手段。
Ctrl+Space は Windows の日本語入力の切替と衝突するため採用しない。

### 13.2 仕様と変えたもの

| 箇所 | 仕様 | 実装 | 理由 |
|---|---|---|---|
| §8.1 | 倍率80% と「1ページに収める」の両方を入れる | **倍率80%のみ**。印刷範囲を明示 | Excelでは両立せず、fitToPage を入れると倍率が無視されて約85%になり、受入条件2の「お手本と寸法が一致」を満たせなくなる。マス目はA4に収まるよう計算して作るので、1枚に収まることは設計で保証している |
| §3 | 方眼は5mm相当 | **約1cm方眼（1列×3行）** | マスの列幅が10.16mmで固定のため、5mmの縦線はセル罫線では引けない。中学校の作図で使う1cm方眼に寄せた |
| §9 | `sections`（大問）に配点と観点を持つ | **欄ごとに配点と観点**を持ち、合計はその積み上げ | 番号の採番を手動（§4）にしたため、欄を大問に束ねる情報が画面上に存在しない。利用者に見える動き（合計100の警告、観点別合計の反映）は仕様どおり |
| §1 | 依存は JSZip 程度（約100KB）まで同梱可 | **外部ライブラリなし**。ZIP（無圧縮）とOOXMLを自前で生成 | 必要なのは罫線・列幅・行高・文字・印刷設定・2シートだけで、約200行で足りる。読み込みが軽く、中身をすべて確認できる |

### 13.3 用紙のマス目（実装値）

余白から自動計算する。1文字マス = 1列 × 2行。

| 向き | 余白 | マス目 | 印刷範囲 |
|---|---|---|---|
| A4横（国語） | 8/9mm | 27列 × 50行 | 274.3 × 190.5 mm（可能領域 281 × 192） |
| A4縦（他教科） | 8/9mm | 19列 × 72行 | 193.0 × 274.3 mm（可能領域 194 × 279） |
| A4横 | 12mm | 26列 × 48行 | お手本 R6 と同じマス数 |

列幅6.125・行高13.5pt・倍率80%はお手本と同一。1文字マスの印刷実寸は
**幅10.16mm × 高さ7.62mm**で、お手本と完全に一致する。

### 13.4 ファイル名について

ブラウザでHTMLを直接開くと（file://）、blob や data のURLが別オリジン扱いになり、
ダウンロード時にファイル名が失われることがある。そのため保存は
**File System Access API の保存ダイアログを主経路**とし、使えない環境では
ダウンロードしたうえで、付けるべきファイル名を画面に出す。

## 14. 解答欄の並び（v1.1 で追加）

作成者の指摘により、お手本 R6 の列構造を調べ直して反映した。

### 14.1 お手本の構造（実測）

お手本の P列・Q列を上から追うと、**すべてのラベルが1行の枠つきセル**で、
解答欄の直前に置かれている。

```
P列                     Q列
行2  四     ← 大問番号   行2  三     ← 大問番号
行3  問一   ← 問番号     行3  (1)    ← 小番号
行4  ①     ← 小番号     行4〜11     解答欄（4文字分）
行5〜7      解答欄       行12 (2)
行8  ②                  行13〜20    解答欄
行9〜11     解答欄       行21 (3)
```

つまり **番号は解答欄の付属物**であり、同じ列の中に
「問番号 → 小番号 → 解答欄 → 小番号 → 解答欄 …」と積み上がる。

### 14.2 実装

- **欄は「番号欄」を必ず持つ**。カーソル位置が番号欄になり、解答欄はその次から始まる
  - 縦書き：番号欄は 1列 × 1行（解答欄の1行上）
  - 横書き：番号欄は 1列 × 2行（解答欄の1列左）
  - 番号欄には細罫線の枠を引く（お手本の `三マス君` `字数解答欄作成` と同じ）
- 欄を置いたあと、カーソルは**次の番号欄の位置**へ進む（欄と欄の間は空けない）
- **番号スタンプは番号欄を優先する**。選んだ範囲に番号欄が含まれていれば、
  そこだけに振る。列をまるごと選んで P を押すだけで (1)(2)(3)… が正しく入る。
  番号欄が無ければ、解答欄の中を避けて選択範囲に振る
- 番号欄以外のセルに番号を振ると、そのセルにも枠が付く（大問番号・問番号用）
- 番号欄の上にカーソルを置いて Space を押すと、その欄の設定が開く
- 教科テンプレは、問番号と小番号まで入った状態で始まる

### 14.3 前置き・後置き文字の置き場所

隣の欄とぶつかるため、**解答欄の内側**（先頭のマスと末尾のマス）に入れる。

```
(1) │ x＝            cm² │
```

答えのみ欄の既定の大きさを、これが収まるように広げた（横書き8文字分、縦書き4文字分）。
模範解答は前置き・後置きのマスを避けて入る。文字で埋まって答えの場所が残らないときは警告する。

### 14.4 字数指定の記述が分かれる列数

番号欄が1行使うため、A4横（50行）では1列あたり**24文字**になる。
50字は 17+17+16 の3列に均等分割される（1列25文字は51行必要で、A4に収まらない）。
分割数は「置いた位置から下に何文字入るか」で決まり、常に均等に割る。

## 15. 大問と問の並べ方（v1.2 で確定）

作成者の説明により、用語と並べ方を確定した。

### 15.1 用語

| 呼び方 | お手本での姿 | 場所 |
|---|---|---|
| **大問** | 太字の「一 二 三」 | お手本の2行目。各ブロックの先頭 |
| **問** | 「問一 問二」 | 大問の中 |
| **小問** | 「(1) (2)」「① ②」 | 問の中。解答欄の直前 |

「行」は縦書きの1本の書き並び、つまり **縦書きでは1列** を指す。

### 15.2 並べ方のきまり

1. **大問は行を分ける。** 新しい大問は次の行（縦書きなら左隣の列、横書きなら次の行）から始める。
   **大問と大問の間に空の行は作らない。**
2. **問・小問は行を開けず、すぐ下（横書きなら右）に続ける。** 欄と欄の間に空きマスを入れない。
3. **下に入らないときは、行を開けずに改行する。** 次の行の頭に置く。
   1つの大問が複数の行にまたがるときは、2行目以降もその大問の本文が始まる行位置に揃える。

### 15.3 実装

- 欄を置こうとして入り切らないときは、**自動で次の行の頭に置き直し**、その旨を画面に出す
- 欄を置いたあとのカーソルは、次の番号欄の位置（空きマスを挟まない）。
  下に1マスも残らなければ次の行の頭へ移る
- 教科テンプレは、大問ごとに行を分け、大問の先頭に **大問番号（一 二 三、太字14pt、枠つき）**、
  各解答欄の番号欄に **小問番号 (1)(2)(3)…** を入れた状態で始まる
- 問番号（問一）が要る大問では、番号欄の無い空きマスにカーソルを置いて `Q` を押すと、
  枠つきの問番号セルになる

### 15.4 お手本との照合（国語テンプレ）

```
22列（大問一）   21列（大問二）   20列（大問三）  19列・18列
 行1 一 [枠]      行1 二 [枠]      行1 三 [枠]     （記述の続き）
 行2 (1)[枠]      行2 (1)[枠]      行2 (1)[枠]
 行3-4 解答欄     行3-6 解答欄     行3〜 記述欄     行3〜 記述欄
 行5 (2)[枠]      行7 (2)[枠]                      ← 先頭行を揃える
 …                …
```

お手本の Q列（行2 三 → 行3 (1) → 行4〜11 解答欄 → 行12 (2)）と同じ構造。

## §24 追加仕様（v1.1）

### §24.1 解答欄の種類を7つに
| キー | 欄 | 備考 |
|---|---|---|
| 1 | シンプル枠 | 変更なし |
| 2 | 記号用 | 解答欄の大きさを **セル3つぶん**（1列×3行）に。Excelでは3行を結合し、答えは中央に入る |
| 3 | 語句 | 2〜5文字想定。**8割ラインは引かない**（`exact:true` 相当） |
| 4 | 記述 | 40字前後想定。8割ライン（以内／ちょうど）を選べる。旧「文字数」欄 |
| 5 | 長方形 | 旧 4 |
| 6 | グラフ | 旧 5 |
| 7 | 書き抜き | 「初め」1マス・○字・「終わり」1マス・○字 をひとつづきに並べる。○は同じ数。見出しのマスは結合し、模範解答は見出しを飛ばして文字マスに入る |

保存ファイルは `version:2`。`version` が 1 のファイルを開いたときは 3→4／4→5／5→6 に読み替える。

### §24.2 番号欄の連結
解答欄が複数の行（列）にまたがるとき、番号欄はその幅（高さ）いっぱいに広がり、左上のセルに `mg:{w,h}` を立てる。
画面では連結範囲の中央に文字を置き、Excel では `mergeCell` を出力する。外周の罫線は `unionBorders()` で左上のセルにまとめる。

### §24.3 セルの削除・移動
- `removeBand(alongRow, from, n, lo, hi, pullBefore)` … 帯を取り除いて詰める共通処理。帯にまるごと入った欄は消え、またがる欄は縮む。
- **K**：セルの削除（縦書き＝上詰め／横書き＝左詰め）
- **Shift+K**：行（列）ごと削除（縦書き＝右へ詰める・右端は固定／横書き＝上へ詰める）
- **Ctrl+X → Ctrl+V**：選んだ範囲にまるごと入っている欄・枠・文字を、カーソルの位置へ移動する。用紙の外やほかの欄に重なる場合は動かさない。

### §27.1 始終の欄の答え
`answerPlan(d,f,text)` … 答えをどのマスに入れるか決める。始終の欄は空白・／・｜で区切ると

### §27.2 始終の答えは2回に分けて入れる（v1.5）

- `splitExtract()` / `joinExtract()` … 答えは1本の文字列のまま（区切りは全角空白）保つ。
  `commitInput` の `kind:'answerPart'` が片側だけを書き換える。

## §29 枠も対象に・字の自動調整（v1.7）

- シンプル枠に `id`（`v◯`）を持たせ、`decoBox(v)` で欄と同じ形（`{id,type:0,rects:[v]}`）に包む。

  1. 1文字マスに1字で入るならそのまま（11pt）
  2. 入らなければ `fineCells()`（セル1つに1字）に切り替え、9pt にする
  3. 連結した1マス（記号用・カスタム）は `markSize(文字数)` で字を小さくして1マスに収める
