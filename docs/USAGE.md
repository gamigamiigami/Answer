# 解答用紙メーカー 使い方

`answer-sheet-maker.html` をダブルクリックするだけで開きます。インストール不要、通信は一切しません。

---

## 1. 起動画面で選ぶ

| ボタン | 中身 |
|---|---|
| 前回の続き | このPCに残っている作業を開く |
| 作業ファイルを開く | 保存した `.json` を開く |
| 教科テンプレから | 国語・数学・英語・理科・社会の標準構成が入った状態で始める（おすすめ） |
| 白紙から | 用紙だけの状態で始める |

タイトル・氏名欄・観点別得点枠は最初から入っています。

---

## 2. 画面は2つのモードだけ

```
🟦 置くモード（いつもの状態）  カーソルは青
   キーはすべて命令。文字は絶対に入りません。

🟩 入力モード（Enter で入る）  カーソルは緑、上の帯も緑
   日本語入力がそのまま使えます。Enter で確定、Esc で取り消し。
```

上の帯とカーソルの色で、今どちらかが常に分かります。

---

## 3. キー一覧（ボタンにも書いてあります）

### 欄を置く
| キー | 欄 | 聞かれること |
|---|---|---|
| 1 | 記号（一文字） | なし |
| 2 | 記号（複数） | 個数 |
| 3 | 漢字・語句 | マス数 |
| 4 | 記述（字数指定） | 字数、以内（8割ライン）／ちょうど |
| 5 | 答えのみ | 欄数 |
| 6 | グラフ・作図 | 方眼／白枠、大きさ |
| 7 | 自由記述枠 | 高さ |

**欄には番号欄が付いてきます。** カーソルの位置が番号欄になり、解答欄はその次から始まります。
お手本のExcelと同じく、1つの列に

```
問一
（１）
［ 解答欄 ］
（２）
［ 解答欄 ］
```

と積み上がります。置き終わるとカーソルは次の番号欄の位置に進むので、そのまま続けて置けます。

**並べ方のきまり**

- **大問**（太字の 一 二 三）は行を分けます。新しい大問は左隣の列から。間に空の列は作りません
- **問・小問**は行を開けず、すぐ下に続けます
- 下に入らないときは、行を開けずに次の列の頭へ自動で置き直します（画面にその旨が出ます）

### 番号を振る（セルを選んでから押す）
| キー | 振るもの |
|---|---|
| D | 大問番号　一 二 三 … |
| Q | 問番号　問一 問二 … |
| P | 小問番号　(1) (2) … |
| M | 丸番号　① ② … |
| A | カナ　ア イ ウ … |

押すと開始番号を聞かれます。大問ごとに選んで振ってください（自動では区切りません）。

**番号欄があるところだけに入ります。** 欄をいくつか置いた列を `Shift+↓` でまとめて選んで `P` を押せば、
解答欄のマスには入らず、番号欄にだけ (1)(2)(3)… が順に入ります。1か所ずつ選ぶ必要はありません。

番号欄以外のセルに振ると、そのセルにも枠が付きます（大問番号や問番号に使えます）。

### 罫線（基本）
| キー | 動き |
|---|---|
| W | **シンプル枠**　選んだ範囲の外側に罫線を引く（もう一度押すと外れる） |
| I | **挿入**　選んだ分だけ空きを作り、続きを押し出す（縦書きは下へ、横書きは右へ） |
| T | **普通線モード ⇄ 太線モード**　これから引く罫線の太さ。今どちらかは上の帯に出ます |
| （ボタン） | **全部消す**　罫線と文字をすべて消す。タイトル・氏名欄・得点枠は残ります |

解答欄そのものは「欄を置く」の 4（文字数）と 1（記号用）で作ります。

### 拡大・縮小
| キー | 動き |
|---|---|
| ＋ | 拡大 |
| − | 縮小 |
| 0 | 画面に合わせる |

上のバーのボタンでも操作できます。

### 選ぶ・直す
| キー | 動き |
|---|---|
| ↑ ↓ ← → | カーソル移動 |
| Shift + 矢印 | 四角く選ぶ |
| **Shift + Space** | 離れたセルを1つずつ選ぶ／外す（番号を振る前に使う） |
| Ctrl + クリック | 同上（マウスの場合） |
| Enter / F2 / ダブルクリック | 入力モードへ |
| Space | カーソル位置の欄の設定（配点・観点・完答・前後の文字） |
| T | 選んだ範囲を太枠に |
| Delete | 選んだ範囲を消す |
| Ctrl + Z / Ctrl + Y | 戻す／やり直す |
| Esc | 選択を解除 |

**選んだ範囲は、操作しても戻しても残ります。** 範囲を選んで問番号を振り、Ctrl+Z で戻すと選んだままなので、そのまま (1) に振り直せます。Excel と同じ感覚です。

## 4. よくある作り方

**問一 (1)〜(5) の記号問題**
1. `1` を5回押す（番号欄つきの記号欄が5つ縦に並ぶ）
2. 先頭に戻って `Shift+↓` で5つ分をまとめて選ぶ
3. `P` → 開始番号 1 → Enter　→ 番号欄にだけ (1)〜(5) が入る
4. いちばん上の空きセルで `D` を押せば大問番号「一」、`Q` を押せば「問一」が入る（枠も付きます）

**五十字以内で書きなさい**
1. `4` → 字数 50 → 「以内」のまま Enter
2. 1列に入り切らなければ自動で2列（25字×2）に分かれ、8割ラインも正しい位置に入ります

**「〜から。」を欄の下に付ける**
1. 付けたいマスへ移動して `Enter`
2. 「から。」と打って `Enter`（1マスに1文字ずつ並びます）

**数学の「x＝　　cm²」**
1. `5` で答えのみ欄を置く
2. その欄の上で `Space` → 前に付ける文字 `x＝`、後に付ける文字 `cm²`
   （文字は欄の内側に入ります。狭いときは欄を大きくしてください）

---

## 5. 模範解答

画面左下の「模範解答」タブに切り替え、欄の上で `Enter` を押して答えを打つだけです。
解答用紙と同じ枠から作るのでズレません。Excel出力にも2枚目のシートとして入ります。

答えの文字は **1文字マス（2行）の真ん中** に入ります。Excel ではその2行を結合して中央に置くので、印刷してもマスの中央に来ます。

---

## 6. 出力

| ボタン | 中身 |
|---|---|
| **Excel出力** | 正本。解答用紙と模範解答の2シート。A4・向き・倍率80%・余白・中央印刷まで入っています。出力後にExcelで手直しできます |
| PDF（確認用） | 画面の印刷から保存。印刷設定は「用紙A4・余白なし・倍率100%・ヘッダーとフッターはオフ」にしてください |
| 作業ファイルを保存 | 来年また開いて直せる `.json`。2回目からは上書き保存になります |

---

## 7. 気をつけること

- **一時保存はこのPCの中だけ**に残ります。共用PCや環境復元のあるPCでは消えることがあります。大事な作業は「作業ファイルを保存」で手元に残してください。
- 一時保存に模範解答を含めるかどうかは ⚙ で選べます。既定は**含めない**（共用PC対策）です。
- 用紙は必ずA4・1枚です。はみ出す置き方をしようとすると、置かずに理由を出します。
- 配点の合計が100でないときは、画面下に黄色で出ます。
