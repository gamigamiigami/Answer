# てすとも君 使い方

`answer-sheet-maker.html` をダブルクリックするだけで開きます。インストール不要、通信は一切しません。

---

## 1. 起動画面で選ぶ

| ボタン | 中身 |
|---|---|
| 前回の続き | このPCに残っている作業を開く |
| 作業ファイルを開く | 保存した `.json` を開く |
| 教科テンプレから | 国語・数学・英語・理科・社会の標準構成が入った状態で始める（おすすめ） |
| 白紙から | 用紙だけの状態で始める |

タイトル・氏名欄・観点別得点枠は最初から入っています。

---

## 2. 画面は2つのモードだけ

```
🟦 置くモード（いつもの状態）  カーソルは青
   キーはすべて命令。文字は絶対に入りません。

🟩 入力モード（Enter で入る）  カーソルは緑、上の帯も緑
   日本語入力がそのまま使えます。Enter で確定、Esc で取り消し。
```

上の帯とカーソルの色で、今どちらかが常に分かります。

---

## 3. ボタンとキー

左の道具は上から「線の太さ → 欄を置く → 番号を振る → その他」の順です。
描画タブに切り替えると、真ん中が「描く」の道具に入れ替わります。

### 線の太さ（一番上）
| キー | 動き |
|---|---|
| Shift + 1 | **普通線** |
| Shift + 2 | **太線** |

これから引く罫線の太さです。シンプル枠にも、新しく置く欄にも、描画の線にも効きます。
**太線モードのときは、番号欄と解答欄のどちらも外枠が太線**になります。

### 欄を置く
| キー | 欄 | 聞かれること |
|---|---|---|
| 1 | シンプル枠 | なし（選んだ範囲に罫線を引く。引いたらカーソルは次へ進みます） |
| 2 | 記号用 | なし（記号1文字の解答欄。セル3つぶんの大きさ） |
| 3 | 始終 | 最初と最後の字数（同じ数）。「初め」○字・「終わり」○字 の順に並びます。**番号欄と解答欄の外枠は太線**です |
| 4 | 語句 | 字数（2〜5文字くらいむけ。8割ラインは引きません） |
| 5 | 記述 | 字数（40字前後むけ）、以内（8割ライン）／ちょうど |
| 6 | 長方形 | 縦（マス）× 横（マス） |
| 7 | グラフ | 横（マス）× 縦（マス）。xyグラフで原点に O が入ります |
| 8 | 漢字 | マス数（区切りの点線なし）。**置いた列は自動でお手本と同じ1.3倍の幅**になります |
| 9 | カスタムA | 登録したセル数の解答欄（記号用と同じ形。3マスにすれば記号用と同じ大きさ） |
| 0 | カスタムB | 同上。2つ登録しておけます |

**キーは「ボタンの並び順」です。** 並びを変えるとキーも入れ替わります（下記）。

### ボタンの並び・カスタム欄
「欄を置く」の下の **［ボタンの並び・カスタム欄］** を押すと、

- **↑↓ で並べ替え**できます。上から順に **1 2 3 … 9・0** のキーになります
- **カスタムA・B のセル数**をここで登録します（ボタンの名前が「3マス」のように変わります）
- 「もとの並びに戻す」で既定の順に戻せます

並びと登録したセル数は、このパソコンに覚えておきます。

字数は前に入れた数を覚えているので、同じ欄を続けて置くときは Enter だけで置けます。

### 番号欄は解答欄の幅にそろいます

解答欄が2列（2行）にまたがるときは、その上（左）の番号欄も同じ幅に広がり、**1つのマスに連結**されます。
Excel に出したときも結合セルになるので、問一・(1) などを入れても位置がずれません。

**範囲を選んでから押すと、その中に入るだけ並びます。** 記号を16個置くのも2操作です。

```
Ctrl+Shift+↓ で列の下まで選ぶ → 2 を押す → 入るだけ記号欄が並ぶ
```

範囲を選んでいなければ、1キーで1個だけ置きます。

**2〜5 には番号欄が付いてきます。** カーソルの位置が番号欄になり、解答欄はその次から始まります。
お手本のExcelと同じく、1つの列に

```
問一
（１）
［ 解答欄 ］
（２）
［ 解答欄 ］
```

と積み上がります。置き終わるとカーソルは次の番号欄の位置に進むので、そのまま続けて置けます。

**並べ方のきまり**

- **大問**（太字の 一 二 三）は行を分けます。新しい大問は左隣の列から。間に空の列は作りません
- **問・小問**は行を開けず、すぐ下に続けます
- 下に入らないときは、行を開けずに次の列の頭へ自動で置き直します

### 番号を振る（セルを選んでから押す）
| キー | 振るもの |
|---|---|
| D | 大問番号　一 二 三 … |
| Q | 問番号　問一 問二 … |
| P | 小問番号　(1) (2) … |
| M | 丸番号　① ② … |
| A | カナ　ア イ ウ … |

押すと開始番号を聞かれます。大問ごとに選んで振ってください（自動では区切りません）。

**大問番号は横に広げて選ぶと、その幅いっぱいの1つの枠になります。** お手本のExcelと同じ見た目です。
（縦書きで1行ぶん、横書きで1列ぶんを複数マス選んで `D`）

**番号欄があるところだけに入ります。** 欄をいくつか置いた列を `Shift+↓` でまとめて選んで `P` を押せば、
解答欄のマスには入らず、番号欄にだけ (1)(2)(3)… が順に入ります。

番号欄以外のセルに振ると、そのセルにも枠が付きます（大問番号や問番号に使えます）。

### その他
| キー | 動き |
|---|---|
| I | **挿入 ↓**（横書きは →）　Excel の挿入と同じ。**選んだマスの数だけ**その位置に差し込みます。枠の途中なら**枠そのものが広がり**、枠の外なら続きを押し出します |
| Shift + I | **挿入 ←**（横書きは ↓）　行そのものを差し込んで、続きの行を押し出す。**縦書きでは右側は動きません**（右が読み始めのため） |
| K | **削除 ↑**（横書きは ←）　選んだマスを取り除いて詰める。Excel の「セルの削除（上方向にシフト）」と同じです |
| Shift + K | **削除 →**（横書きは ↑）　行（列）ごと取り除いて詰める。**縦書きでは右端は動きません** |
| T | **対象の切り替え**　☑を付ける相手を「番号のマス」と「解答欄」で切り替える |
| Shift + Enter | **一覧でまとめて答えを入れる**（模範解答タブ）　1行1問の小窓が開きます |
| W | **列の幅**　選んだ列の幅を％で変える（ふつうの列＝100、漢字の欄＝130）。広げたぶんは左端の空いている列を減らして詰め、**必ずA4・1枚に収めます**。左に空きがなければ変えずに知らせます |
| Ctrl + A | **ぜんぶ選ぶ**　用紙全体を選ぶ（模範解答タブなら、続けて Enter で全問まとめて入力） |
| Ctrl + X | **移動（切り取り）**　動かしたい欄を囲むように範囲を選んでから押す |
| Ctrl + V | **ここへ動かす**　カーソルの位置へ、切り取ったものをまとめて動かす |
| Delete | **消す**　選んだ範囲の欄・罫線・文字を消す（詰めません） |
| （ボタン） | **全部消す**　罫線と文字をすべて消す。タイトル・氏名欄・得点枠は残ります |
| Enter | **文字を入れる**（次の項を参照） |
| Space | **欄の設定**　配点・観点・8割ライン・欄に入れる文字。**範囲を選んでいれば、かかる欄すべてにまとめて配点を入れられます** |
| Shift + Space | **セルの選択**　離れたマスを1つずつ選ぶ／外す |

### 拡大・縮小
| キー | 動き |
|---|---|
| ＋ | 拡大 |
| − | 縮小 |
| Shift + 0 | 画面に合わせる（0 は欄のボタンに使うため） |

### 選ぶ・直す
| キー | 動き |
|---|---|
| ↑ ↓ ← → | カーソル移動 |
| **Ctrl + 矢印** | **その向きの端まで一気に移動**（Excel と同じ） |
| Shift + 矢印 | 四角く選ぶ |
| **Ctrl + Shift + 矢印** | **端まで一気に選ぶ** |
| Ctrl + クリック | 離れたマスを選ぶ（マウスの場合） |
| Ctrl + Z / Ctrl + Y | 戻す／やり直す |
| Esc | 選択を解除 |

**選んだ範囲は、操作しても戻しても残ります。** 範囲を選んで問番号を振り、Ctrl+Z で戻すと選んだままなので、そのまま (1) に振り直せます。Excel と同じ感覚です。

## 4. 文字を入れる（Enter）

押した場所によって3通りに分かれます。

**① 解答欄やシンプル枠の上で押したとき**
「文字を入れる」の小窓が出ます。文字と **位置（先頭／中央／お尻）** を選びます。

```
［　　　　　　　から。］   ← お尻
［x＝　　　　　　　　　］   ← 先頭
```

**模範解答とちがい、1マス1文字にはなりません。** 縦書きなら1行に1字ずつ詰めて入るので、
「から。」は3行ぶんに収まります（解答欄のマスを3つ使いません）。

**② 範囲を選んで押したとき**
選んだマスすべてに同じ文字がまとめて入ります。記号の選択肢を並べるときなどに。

**③ それ以外のセルで押したとき**
その場に文字を入れます。1マスに1文字ずつ、書き方向に並びます。

模範解答タブでは、欄の上で Enter を押すと答えを入れられます。

---

## 5. 描画タブ

用紙の上に直線や点を足せます。作図の下図や、グラフの補助線に使ってください。

| 道具 | 使い方 |
|---|---|
| 直線（1） | 用紙の上をドラッグ |
| 点（2） | 用紙の上をクリック |
| 消しゴム（3） | 消したい線や点の近くをクリック |

マスの半分きざみで吸い付くので、まっすぐ引けます。線の太さは「線の太さ」の切り替えに従います。
描いたものは解答用紙にも模範解答にも出ます。Excel 出力では図形として入ります。

## 6. 模範解答

画面左下の「模範解答」タブに切り替え、欄の上で `Enter` を押して答えを打つだけです。
解答用紙と同じ枠から作るのでズレません。Excel出力にも2枚目のシートとして入ります。

答えの文字は **1文字マス（2行）の真ん中** に入ります。Excel ではその2行を結合して中央に置くので、印刷してもマスの中央に来ます。

---

## 7. 出力

| ボタン | 中身 |
|---|---|
| **Excel出力** | 正本。解答用紙と模範解答の2シート。A4・向き・倍率80%・余白・中央印刷まで入っています。出力後にExcelで手直しできます |
| PDF（確認用） | 画面の印刷から保存。印刷設定は「用紙A4・余白なし・倍率100%・ヘッダーとフッターはオフ」にしてください |
| 作業ファイルを保存 | 来年また開いて直せる `.json`。2回目からは上書き保存になります |

---

## 8. 気をつけること

- **一時保存はこのPCの中だけ**に残ります。共用PCや環境復元のあるPCでは消えることがあります。大事な作業は「作業ファイルを保存」で手元に残してください。
- 一時保存に模範解答を含めるかどうかは ⚙ で選べます。既定は**含めない**（共用PC対策）です。
- 用紙は必ずA4・1枚です。はみ出す置き方をしようとすると、置かずに理由を出します。
- 配点の合計が100でないときは、画面下に黄色で出ます。配点を入れていないうちは得点枠に数字を出しません。
- **シンプル枠にも配点を入れられます。** 証明や作図の大きな枠を選んで Space を押してください。
- **戻す（Ctrl+Z）はタブごとです。** 解答用紙タブで戻しても、模範解答や描いたものは消えません。
- 用紙の向きや文字の向きを変えると欄がはみ出す場合は、先に確認の小窓が出ます。
- 欄や文字が用紙からはみ出している間は、画面下に赤で「◯か所が用紙の外にあります」と出ます。

## まとめて作る（お手本のような用紙を数操作で）

同じ形の欄がたくさん並ぶ大問は、**範囲を選んでから1回押すだけ**で作れます。

1. **欄をまとめて置く**　置きたい範囲（例：4列×45行）を選んで `8`（漢字）→ マス数を入れる
   → 入るだけ並びます。**置いたあとも選んだ範囲は残ります。**
2. **番号をまとめて振る**　そのまま `M`（①）→ 開始番号を入れる
   → 読む順（縦書きは右の列から上→下）に ①②③… と入ります。解答欄の中には入りません。
3. **大問の見出し**　その大問の幅ぶんの1行を選んで `D` → 4列ぶんの枠にまとめた「一」が入ります。
4. **模範解答をまとめて入れる**　模範解答タブに切り替え、`Ctrl+A`（または範囲を選ぶ）→ `Enter`
   → 1行に1問ずつ、読む順に並べて貼り付け → `Ctrl+Enter` で決定。
   欄に入りきらない答えがあれば、その数を知らせます。

この手順だと、20問ぶんの解答欄・番号・模範解答が **15操作ほど**で入ります。


---

## ☑ で対象を決めてから入れる

**範囲をドラッグで選ぶと、その中の欄に ☑ が付きます。** ☑が付いているあいだは、

- **クリックで付け外し**できます（対象から外れている欄には ☐ が出ます。押せば入ります）
- **T** で、☑を付ける相手を「**番号のマス**」⇄「**解答欄**」に切り替えられます
  （模範解答タブでは自動で「解答欄」になります）
- **D Q P M A** を押すと、☑を付けたところだけに、その順で番号が振られます
- **Enter** を押すと、**☑の最初のところに入力欄が出ます**。入れて Enter を押すと**次の☑へ飛びます**。
  用紙を見ながら続けて入力でき、次のマスを選び直す手間がありません。Esc でやめられます

一覧に貼り付けたいときは **Shift+Enter**（模範解答タブ）で、1行1問の小窓が開きます。

### 始終の欄の答え
☑ を付けて **Enter** で入力を始めると、**「初め」→ Enter →「終わり」→ Enter → 次の欄** と進みます。
区切り記号を打つ必要はありません。入力欄はそのつど、そのマスの上に出ます。

1つの欄に手で入れるときは、**空白（または ／）で区切って**ください。

    「不便　出そう

と入れると、「不便 が「初め」の側、出そう が「終わり」の側に入ります。


---

## 枠（シンプル枠）も ☑ の対象になります

外枠を引いたところは、すべて☑を付けられます。とりあえず次のように見分けます。

| 枠の大きさ | 扱い |
|---|---|
| **1マスだけ**の枠 | **番号のマス**（問一・(1) などを振る先） |
| **2マス以上**の枠 | **解答欄**（模範解答を入れられる） |

自動の見分けが合わないときは、**T** で対象を切り替えて、**☐をクリックして追加**してください。

### 答えが入りきらないときは字を小さくします
枠や欄に1文字ずつ入れて足りないときは、**セル1つに1字ずつ詰めて、字を小さく**して入れます。
記号用・カスタムのマスは、文字数に合わせて字を小さくして1マスに収めます（「ウ・エ」など）。

### 入力欄の位置
続けて入力するときの入力欄は、**解答欄にかぶらないように**、縦書きなら左どなり、
横書きなら下に出ます。


---

## 画面まわり

- **Z**（または上の「⤢ 大きく」）で、**道具と帯を隠して用紙だけを大きく**表示します。
  Z か Esc でもどります。1366×768 の画面で、ふつうの表示の約120％の大きさになります。
- モードの知らせ（置くモード／入力中／☑）は、**下の帯の左はし**に色つきで出ます。
- 左のボタンは、1366×768 の画面でもスクロールなしで全部見えます。

## 文字の大きさ
**欄の設定（Space）**に「文字の大きさ（％）」を足しました。100がふつうです。
範囲を選んでまとめて設定すれば、選んだ欄ぜんぶの文字の大きさを一度に変えられます。
（入りきらないときは、これとは別に自動で小さくなります）

## 横書きの教科のならび
国語以外は、**タイトルが一番上、氏名欄と得点枠が一番下**に入ります。解答欄はその間に置きます。

## 縦書きのカッコ
国語（縦書き）では、（ ） 「 」 ー などを**たて向きの字**に置きかえて出します。


---

## 迷ったら ？（F1）

右上の **？** を押すと、**そのときのキー割り当てのまま**使い方が出ます（ボタンを並べ替えても正しく出ます）。

## 楽をするコツ

- **いくつ置くか**：欄の小窓の一番下で数を指定できます。範囲を選んでいるときは **0＝入るだけ**。
- **大問の見出し**：欄を置いた直後（☑が付いたまま）に **D** を押すと、**その大問の幅いっぱいの見出し**が
  すぐ上に入ります。選び直す必要はありません。
- **番号は続きから**：2回目からは、前に振った続きの番号が最初から入っています。
- 画面の文字が小さいときは、**⚙ → 画面の文字 → 大きめ**。
