# 解答用紙メーカー 使い方

`answer-sheet-maker.html` をダブルクリックするだけで開きます。インストール不要、通信は一切しません。

---

## 1. 起動画面で選ぶ

| ボタン | 中身 |
|---|---|
| 前回の続き | このPCに残っている作業を開く |
| 作業ファイルを開く | 保存した `.json` を開く |
| 教科テンプレから | 国語・数学・英語・理科・社会の標準構成が入った状態で始める（おすすめ） |
| 白紙から | 用紙だけの状態で始める |

タイトル・氏名欄・観点別得点枠は最初から入っています。

---

## 2. 画面は2つのモードだけ

```
🟦 置くモード（いつもの状態）  カーソルは青
   キーはすべて命令。文字は絶対に入りません。

🟩 入力モード（Enter で入る）  カーソルは緑、上の帯も緑
   日本語入力がそのまま使えます。Enter で確定、Esc で取り消し。
```

上の帯とカーソルの色で、今どちらかが常に分かります。

---

## 3. ボタンとキー

左の道具は上から「線の太さ → 欄を置く → 番号を振る → その他」の順です。
描画タブに切り替えると、真ん中が「描く」の道具に入れ替わります。

### 線の太さ（一番上）
| キー | 動き |
|---|---|
| Shift + 1 | **普通線** |
| Shift + 2 | **太線** |

これから引く罫線の太さです。シンプル枠にも、新しく置く欄にも、描画の線にも効きます。
**太線モードのときは、番号欄と解答欄のどちらも外枠が太線**になります。

### 欄を置く
| キー | 欄 | 聞かれること |
|---|---|---|
| 1 | シンプル枠 | なし（選んだ範囲に罫線を引く。引いたらカーソルは次へ進みます） |
| 2 | 記号用 | なし（記号1文字の解答欄） |
| 3 | 文字数 | 字数、以内（8割ライン）／ちょうど |
| 4 | 長方形 | 縦（マス）× 横（マス） |
| 5 | グラフ | 横（マス）× 縦（マス）。xyグラフで原点に O が入ります |

**範囲を選んでから押すと、その中に入るだけ並びます。** 記号を16個置くのも2操作です。

```
Ctrl+Shift+↓ で列の下まで選ぶ → 2 を押す → 入るだけ記号欄が並ぶ
```

範囲を選んでいなければ、1キーで1個だけ置きます。

**2〜5 には番号欄が付いてきます。** カーソルの位置が番号欄になり、解答欄はその次から始まります。
お手本のExcelと同じく、1つの列に

```
問一
（１）
［ 解答欄 ］
（２）
［ 解答欄 ］
```

と積み上がります。置き終わるとカーソルは次の番号欄の位置に進むので、そのまま続けて置けます。

**並べ方のきまり**

- **大問**（太字の 一 二 三）は行を分けます。新しい大問は左隣の列から。間に空の列は作りません
- **問・小問**は行を開けず、すぐ下に続けます
- 下に入らないときは、行を開けずに次の列の頭へ自動で置き直します

### 番号を振る（セルを選んでから押す）
| キー | 振るもの |
|---|---|
| D | 大問番号　一 二 三 … |
| Q | 問番号　問一 問二 … |
| P | 小問番号　(1) (2) … |
| M | 丸番号　① ② … |
| A | カナ　ア イ ウ … |

押すと開始番号を聞かれます。大問ごとに選んで振ってください（自動では区切りません）。

**大問番号は横に広げて選ぶと、その幅いっぱいの1つの枠になります。** お手本のExcelと同じ見た目です。
（縦書きで1行ぶん、横書きで1列ぶんを複数マス選んで `D`）

**番号欄があるところだけに入ります。** 欄をいくつか置いた列を `Shift+↓` でまとめて選んで `P` を押せば、
解答欄のマスには入らず、番号欄にだけ (1)(2)(3)… が順に入ります。

番号欄以外のセルに振ると、そのセルにも枠が付きます（大問番号や問番号に使えます）。

### その他
| キー | 動き |
|---|---|
| I | **挿入 ↓**（横書きは →）　Excel の挿入と同じ。**選んだマスの数だけ**その位置に差し込みます。枠の途中なら**枠そのものが広がり**、枠の外なら続きを押し出します |
| Shift + I | **挿入 ←**（横書きは ↓）　行そのものを差し込んで、続きの行を押し出す。**縦書きでは右側は動きません**（右が読み始めのため） |
| Delete | **消す**　選んだ範囲の欄・罫線・文字を消す |
| （ボタン） | **全部消す**　罫線と文字をすべて消す。タイトル・氏名欄・得点枠は残ります |
| Enter | **文字を入れる**（次の項を参照） |
| Space | **欄の設定**　配点・観点・8割ライン・欄に入れる文字。**範囲を選んでいれば、かかる欄すべてにまとめて配点を入れられます** |
| Shift + Space | **セルの選択**　離れたマスを1つずつ選ぶ／外す |

### 拡大・縮小
| キー | 動き |
|---|---|
| ＋ | 拡大 |
| − | 縮小 |
| 0 | 画面に合わせる |

### 選ぶ・直す
| キー | 動き |
|---|---|
| ↑ ↓ ← → | カーソル移動 |
| **Ctrl + 矢印** | **その向きの端まで一気に移動**（Excel と同じ） |
| Shift + 矢印 | 四角く選ぶ |
| **Ctrl + Shift + 矢印** | **端まで一気に選ぶ** |
| Ctrl + クリック | 離れたマスを選ぶ（マウスの場合） |
| Ctrl + Z / Ctrl + Y | 戻す／やり直す |
| Esc | 選択を解除 |

**選んだ範囲は、操作しても戻しても残ります。** 範囲を選んで問番号を振り、Ctrl+Z で戻すと選んだままなので、そのまま (1) に振り直せます。Excel と同じ感覚です。

---

## 4. 文字を入れる（Enter）

押した場所によって3通りに分かれます。

**① 解答欄やシンプル枠の上で押したとき**
「文字を入れる」の小窓が出ます。文字と **位置（先頭／中央／お尻）** を選びます。

```
［　　　　　　　から。］   ← お尻
［x＝　　　　　　　　　］   ← 先頭
```

**模範解答とちがい、1マス1文字にはなりません。** 縦書きなら1行に1字ずつ詰めて入るので、
「から。」は3行ぶんに収まります（解答欄のマスを3つ使いません）。

**② 範囲を選んで押したとき**
選んだマスすべてに同じ文字がまとめて入ります。記号の選択肢を並べるときなどに。

**③ それ以外のセルで押したとき**
その場に文字を入れます。1マスに1文字ずつ、書き方向に並びます。

模範解答タブでは、欄の上で Enter を押すと答えを入れられます。

---

## 5. 描画タブ

用紙の上に直線や点を足せます。作図の下図や、グラフの補助線に使ってください。

| 道具 | 使い方 |
|---|---|
| 直線（1） | 用紙の上をドラッグ |
| 点（2） | 用紙の上をクリック |
| 消しゴム（3） | 消したい線や点の近くをクリック |

マスの半分きざみで吸い付くので、まっすぐ引けます。線の太さは「線の太さ」の切り替えに従います。
描いたものは解答用紙にも模範解答にも出ます。Excel 出力では図形として入ります。

## 6. 模範解答

画面左下の「模範解答」タブに切り替え、欄の上で `Enter` を押して答えを打つだけです。
解答用紙と同じ枠から作るのでズレません。Excel出力にも2枚目のシートとして入ります。

答えの文字は **1文字マス（2行）の真ん中** に入ります。Excel ではその2行を結合して中央に置くので、印刷してもマスの中央に来ます。

---

## 7. 出力

| ボタン | 中身 |
|---|---|
| **Excel出力** | 正本。解答用紙と模範解答の2シート。A4・向き・倍率80%・余白・中央印刷まで入っています。出力後にExcelで手直しできます |
| PDF（確認用） | 画面の印刷から保存。印刷設定は「用紙A4・余白なし・倍率100%・ヘッダーとフッターはオフ」にしてください |
| 作業ファイルを保存 | 来年また開いて直せる `.json`。2回目からは上書き保存になります |

---

## 8. 気をつけること

- **一時保存はこのPCの中だけ**に残ります。共用PCや環境復元のあるPCでは消えることがあります。大事な作業は「作業ファイルを保存」で手元に残してください。
- 一時保存に模範解答を含めるかどうかは ⚙ で選べます。既定は**含めない**（共用PC対策）です。
- 用紙は必ずA4・1枚です。はみ出す置き方をしようとすると、置かずに理由を出します。
- 配点の合計が100でないときは、画面下に黄色で出ます。配点を入れていないうちは得点枠に数字を出しません。
- **シンプル枠にも配点を入れられます。** 証明や作図の大きな枠を選んで Space を押してください。
- **戻す（Ctrl+Z）はタブごとです。** 解答用紙タブで戻しても、模範解答や描いたものは消えません。
- 用紙の向きや文字の向きを変えると欄がはみ出す場合は、先に確認の小窓が出ます。
- 欄や文字が用紙からはみ出している間は、画面下に赤で「◯か所が用紙の外にあります」と出ます。
