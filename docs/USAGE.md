# てすとも君 かんたんガイド

## 大問を指定して形式・配点を変更する

「模範解答の編集」→「形式・配点・観点をまとめて変更」を開きます。「大問を入力」に `１～５`、`１，２，３，４，５`、`1～3，5` のように入力し、解答形式・配点・観点の変更したい項目を選んで「選んだ内容をまとめて変更」を押します。例えば、大問1を指定して「漢字」を選ぶと、大問1の全問が漢字欄になります。「記述」「表」「英文」「数式」なども選べます。全角・半角どちらも使え、存在しない大問や逆順の範囲は変更前に案内します。

最後に下の「この内容で用紙を更新」を押すと反映します。変更しない項目と指定外の大問は保持します。「全問」「チェックした問題」の指定も引き続き使えます。

## 解答欄の末尾に「から。」などを入れる

解答用紙で欄を1つ選び、左の「解答欄」タブにある「欄に文字を添える（から。など）」を押します。文字列をまとめて入力し、位置を「末尾（下・右）」にします。先頭・中央も選べます。欄の範囲を選んでEnterでも同じ入力画面が開きます。文字は配布用紙と模範解答の両方に印刷され、保存・Excel出力にも残ります。


## 左側の操作タブ

- **解答欄**：欄の追加、表・漢文、番号、文字・配点、見た目。最初はここが開きます。
- **配置**：欄の選択・移動・詰め、得点欄の移動、配置の修正・削除。
- **用紙・設定**：A4の向き・倍率、満点・採点、点検と道具の設定。
- **ページ・画像**：ページの追加・切替・削除・分割、画像の追加と位置・大きさ。

上部で「模範解答」「描画」に切り替えると、左の先頭タブも「答え」「描画」に変わり、その作業の道具を開きます。操作タブは矢印キーとHome／Endでも切り替えられます。用紙の内容はタブの切り替えでは変わりません。


**答えを入力 → 確認 → Excel出力。この流れで解答用紙を作れます。**

## 入力・数式・ページ・画像の改善（2026-10-27）

- **区切りは￥がおすすめ**：`1￥答え、文章の続き￥2￥知`。半角の¥やバックスラッシュも使えます。￥で区切った行の「、」やカンマは答えとして残ります。従来のカンマ形式も利用できます。答えに￥そのものが入るときは、その答えを半角の引用符で囲みます。
- **数字だけの答え**：「答えだけを1行ずつ入力」にチェックすると、12・24・36のような数字も答えになります。大問番号を使う通常の入力とは切り替えて使ってください。
- **入力表**：「入力表を使う・Excelから貼る」で、大問・番号・答え・点数・観点・形式を別々の列に入力できます。Excelからは同じ列順で貼り付けます。
- **指数・組み合わせ**：`1^2`、`x^12`、`x^{n+1}`、`x^(-2)` は指数を右上へ。`3C1`・`nCr`・`5P2` はC/Pの両側を小さな添字にします。数式欄・表・PDF・Excelに共通で反映します。Excelの数式表記は編集可能な図形です。グラフの式ではsin/cos/tan（ラジアン）、log（常用対数）、ln、sqrt、abs、exp、π、原点中心の円 `x^2+y^2=4` も使えます。
- **ふりがな**：`漢字《かんじ》` と入力します。国語の縦書きでは右側、横書きでは上側に表示。読みは自分で入力します。
- **表の編集**：Shift＋Enterでセル内改行。選択した列の幅・行の高さを調整でき、「文章に合わせて行を広げる」で折り返しを保ちます。「解答不要」のセルは未入力の点検から除外します。結合は選択セルを左上として行数×列数を指定。結合先に文字や配点がある場合は、消失を防ぐため先に空にします。「セルごとに配点」を選ぶと表全体の配点はセルの合計になります。
- **作成・更新は1つのボタン**：上部「模範解答の編集」で直し、「この内容で用紙を更新」を押します。答え・配点・観点だけの変更は配置を保ち、形式・番号・寸法・問題数を変えた場合や答えが入りきらない場合は配置し直します。別の更新ボタンや作り直しのチェックはありません。
- **満点・採点**：「満点・採点の設定」で20点・50点などを指定。0は満点との比較を省略します。「点数のみ（観点なし）」「配点なし」も選べます。小数の配点に対応。「模範解答の編集」の「＋ 観点を追加」で任意の観点名（20文字まで）を登録でき、直接入力では `観点:資料活用` と指定できます。主体的に学習に取り組む態度も選択できます。複数ページの合計はテスト全体の点数として表示します。
- **複数ページ**：左でページを追加・切り替え・削除。「読みやすい大きさで分割」は、現在のページを指定倍率を目標に再配置します。完答の組と1問は途中で切りません。画像と手描きの図は最初のページへ残すので、分割後に位置を確認してください。1問だけで大きすぎる場合は、縮小と点検の案内を利用できます。各ページはA4縦／横で、JSONは全ページ、Excelは各ページの解答用紙・模範解答シート、PDFは現在のタブの全ページを出力します。
- **画像・図**：PNG/JPEG/WebPを追加し、位置・幅をmmで調整できます。高さは縦横比を保ちます。「模範解答だけに表示」も可能。描画でも「模範解答だけに描く」を選べます。円・矢印・角度の弧を追加するボタンもあります。
- **罫線**：描画タブの「欄の罫線・英作文の語数」で、横罫線・四線罫・五線譜、英作文の語数の目安を付けられます。先に広い解答欄を選んでください。
- **点検・保存**：小さな文字・手書きマス・折り返しのはみ出し・表の必要セルの未入力を案内します。生成自体は妨げません。一時保存の初期設定は用紙のみで、模範解答・模範解答用の画像と図は除外します。答えも残すには作業ファイルを保存してください。画像が多く一時保存に入らないときも画面に表示します。

## どのモードで作る？

| モード | 作り方 |
|---|---|
| ✎ 模範解答から | 答えを書く → 欄と番号が自動でできる |
| ▦ 見本から | 教科の見本を開く → 必要なところを直す |
| ＋ 白紙から | 場所を選ぶ → 数字キーで欄を追加する |

トップと編集画面には独立した **「使い方」** ボタンがあります。入力画面の **「このモードの使い方」** では、入力から完成までの図解を開けます。

## 数字キーで、欄をポンと追加！

**「解答用紙」タブ → 空いた場所をクリック → 左のボタンにある数字キーを押す → 欄ができる！**

標準では **2＝記号用、4＝語句、5＝記述**。ボタンの並びを変えるとキーも変わるので、画面のキー表示を見てください。ボタンをクリックしても同じ操作ができます。

## 模範解答から作る4つの手順

1. **「模範解答から作る」を押す。** タイトルを入力し、「このタイトルで進む」を押します。
2. **教科を選び、答えを入力する。** 「入力例を試す」で入った例の答えを書き換えると簡単です。「このモードの使い方」もその場で開けます。
3. **「読み取って一覧にする →」を押す。** 番号・答え・点数・観点を確認し、違うところだけ直します。欄の種類と大きさは自動で決まります。「この内容で用紙を作る」で完成です。
4. **確認して「Excel出力」。** 「解答用紙」「模範解答」の両タブを見て確認します。Excelを開き、印刷プレビューを確認してから印刷します。

## 入力の書き方

**基本点数と観点を先に決めたら、「問題番号，答え」だけでOK！**

1. 入力画面の **基本点数** に、1問あたりの点数を入れます。
2. **基本の観点** を選びます。大問ごとに変えるなら **「＋ 大問の範囲を追加」** を押します。
3. 大問番号と答えを書き、**「読み取って一覧にする」** を押します。

たとえば **基本2点／大問1〜3は知識・技能／大問4〜5は思考・判断・表現** と決めれば、次の入力だけで点数と観点も入ります。

```text
1
1，ア
2，太陽
4
1，相手の気持ちを考えたから。
```

**数字だけの行＝大問番号**、**カンマの前＝問題番号**、**後ろ＝答え**です。大問4の問1も2点になり、観点は思考・判断・表現になります。範囲に含まれない大問には基本の観点が入ります。

設定は次回にも引き継ぎ、作業ファイルにも保存します。設定を変更したら、もう一度「読み取って一覧にする」で反映してください。

### 点数や観点が違う問題だけ、後ろに追加

| 入力 | 結果 |
|---|---|
| `1，ア` | 基本点数・その大問の観点 |
| `1，ア，5` | その問だけ5点 |
| `1，ア，思` | その問だけ思考・判断・表現 |
| `1，ア，5，思` | その問だけ5点・思考・判断・表現 |

**個別に書いた指定を優先します。** 知＝知識・技能、思＝思考・判断・表現。半角カンマ・全角カンマ・読点で区切れます。答えに読点がある場合は `1，"こんにちは、先生"` のように答えを半角の引用符で囲みます。

数学・英語・理科・社会も同じ書き方です。**教科を選んでから「入力例を試す」**と、教科に合う例が入ります。

### 小問の①・A・（１）も、そのまま入力

| 小問の形 | 最初の小問 | 続く小問（問番号は省略OK） |
|---|---|---|
| 丸数字 | `1，①，ア` | `②，イ` |
| アルファベット | `2，A，ウ` | `B，エ` |
| かっこ数字 | `3，（１），オ` | `（２），カ` |

たとえば `1，①，ア` は **問1の小問①、答えがア**です。①・A・（１）を自動で判別し、その形を保って印刷します。基本点数と大問ごとの観点は、小問にも入ります。

`1①，ア`・`問一A，ウ` のように続けて書くこともできます。大問を変えると、引き継いでいた問番号はリセットされます。

数字が答えの場合は `2A，12` または `2，A，"12"` と書くと確実です。`2，A，2，知` は従来どおり、**問2の答えがA、2点、知識・技能**として読みます。

### ①②の両方が正解で、まとめて2点にしたい

**「完答開始」と「完答終了」で、1組にする欄を囲みます。**

```text
完答開始，2，し
5，①，ア
②，イ
完答終了
```

| 色分けする部分 | 意味 |
|---|---|
| `完答開始`・`完答終了` | ここから・ここまでが1組の完答 |
| `2` | 組全体の点数（①②を合わせて2点） |
| `し` | 思考・判断・表現。「思」でも可。知識・技能は「ち」か「知」 |
| `5` | 問番号。「問五」の5 |
| `①`・`②` | 問5の中の小問番号 |
| `ア`・`イ` | 各小問の模範解答 |

**上のとおり4行に分けて書きます。** 「②，イ」の行は問5を省略しています。`5，②，イ` と書いても同じです。画面の説明では、これらの部分を文字色だけで対応付けています。

①②は別々の欄で作り、**2つとも正解で2点**として集計します。2点ずつで4点にはなりません。観点は大問の設定を使い、変える場合は `完答開始，2，思` のように開始行へ指定します。点数は開始行へまとめて書いてください。

画面で組を作る場合は、確認画面の **「配点・観点をまとめて変更」** を開く → 同じ大問の連続する欄にチェック → 組全体の点数を選ぶ → **「チェックした欄をまとめて完答」**。組のどれかの点数・観点を直すと、組全体に反映します。個別採点に戻すときは **「完答の組を解除」** し、各欄の点数を見直してください。

### （１）の中に、さらにA・B・Cがある場合

```text
問一（１）A，ア
B，イ
C，ウ
```

**問一 →（１）→ A・B・C** の3段階になります。続くB・Cは「問一（１）」を引き継ぎます。最初の行を `1，（１），A，ア` とカンマで分けても同じです。確認画面には「問番号」「小問番号」「小問内の番号」が別々に出るので、必要な部分だけ直せます。

次の（２）へ移るときは `問一（２）A，エ`、続けて `B，オ` のように書きます。A〜Cをまとめて完答にする場合も、その行を「完答開始」「完答終了」で囲めます。

### 答えだけでも入力できます

```text
ア
太陽
相手の気持ちを考えたから。
```

番号は自動で付き、点数・観点は上の設定に従います。数字だけの答えは大問と区別するため `1，12` の形で書いてください。点数をまだ決めない場合は基本点数を0点にし、あとで確認画面から変更できます。

## 直したい・続きから作りたい

- **答えを直す：** 上部の「模範解答の編集」を押します。用紙を作り直すと手動の配置・描画も置き換わるので、確認欄を読んでから進めます。
- **続きから作る：** 「作業ファイルを保存」で編集用ファイル（.json）を保存。次回は「作業ファイルを開く」で再開します。
- **困ったら：** 「使い方」。作り方・欄の置き方／模範解答から作る／詳しい機能の3タブがあります。

小問、字数指定、初終、完答、欄の幅や高さ、手動配置、キー操作は **[詳しい使い方](USAGE-DETAILS.md)** で確認できます。


## 入力ガイドの色分け

入力例・説明・完成イメージの同じ項目を同じ色で表示します。青＝大問（数字だけの行）、緑＝問題番号、茶＝答え、紫＝点数、桃＝観点。色名と項目名も併記するため、色だけで判断する必要はありません。入力画面の書き方図も同じ配色です。入力例はそのままコピーして使えます。色は説明用の目印で、用紙の印刷色は変わりません。

色分けは文字色だけで表示します。項目ごとの背景色や色付きの強い枠線は使わず、説明と入力例を落ち着いた見た目で対応づけます。

## 漢文の□・送り仮名・返り点

「欄を置く」の **□ 漢文** を押し、□の数を選びます。漢文欄を選んで **漢文の文字・返り点** を押すと、プレビューを見ながら「□の中」「右下」「左下」に別々に入力できます。漢字だけでなく、読む順序の数字も入れられます。

- **用紙にも印刷：チェックあり** → 問題として最初から示す文字。
- **チェックなし** → 模範解答だけに出す文字。
- 何も入れない位置は空欄のままです。□は縦に並び、文字の周りに余白を取ります。

模範解答から作る場合は、最後に「漢文」を付けます。

```text
1
1,不/ズ/レ 学/ブ/,4,知,漢文
2,1 4//レ 3//レ 2,4,知,漢文
```

| 入力 | □の中 | 右下 | 左下 |
| --- | --- | --- | --- |
| `不/ズ/レ` | 不 | ズ | レ |
| `学/ブ/` | 学 | ブ | 空欄 |
| `4//レ` | 4 | 空欄 | レ |
| `□//レ` | 空欄 | 空欄 | レ |

**空白で区切ると次の□**です。読み取った一覧の「□・右下・左下を入力」で、位置ごとの入力・用紙への印刷を変更できます。1つの欄に□は1〜12個、中は2文字まで、右下・左下は各4文字まで。Excel出力でも□と文字の位置を保ちます（編集可能な図形として出力）。

## 表の解答欄

左の「表を作る」で列数（横）×行数（縦）を指定できます。作成後は表をダブルクリックするか、「表の行・列を編集」を押します。

セルを選び、「上／下に行を追加」「左／右に列を追加」「行／列を削除」で変更できます。最後のセルでTabを押すと次の行が増えます。Excelから複数セルを貼り付けることもできます。

見出しや問題文は、そのセルを選んで「解答用紙にも印刷」をチェックします。チェックのない文字は模範解答だけに出ます。「表を反映」で保存し、作業ファイル・印刷・Excel出力にも反映されます。表は1〜20列 × 1〜40行です。

模範解答から作る場合は、欄の種類で「表」を選び「表の行・列・文字を編集」を開きます。入力例は `1，，4，知，表，3×4`（3列×4行・4点）です。

## A4を超える用紙と、拡大・縮小

問題が多くても、作業領域を広げて全問を生成します。左の「用紙と大きさ」でA4縦・横を選び、倍率を1〜400％で調整できます。「A4に合わせる」で全体が用紙に収まります。倍率は文字・欄・図に共通で、保存・印刷・Excel出力にも反映します。上部の画面ズームは、画面の表示だけを変えます。

## 解答欄をまとめて移動する

「解答用紙」タブの左側にある「解答欄を全部選ぶ」→「右に詰める」で、番号・見出し・模範解答を保ったまま解答欄を右へ寄せられます。一部だけ動かす場合は、用紙上で欄を囲んで選び、上下左右のボタンを押します。欄の一部を選んでも、その欄と番号をまとめて動かします。

「選んだ欄をドラッグ」をONにすると、選んだ欄をマウスや指で動かせます。矢印キーで1マス、Shift＋矢印キーで5マスずつ移動し、Escで移動モードを終了します。「戻す・やり直す」にも対応します。

「得点欄を空いた場所へ」には、名前の下・解答欄の下へ置くボタンがあります。縦書きで氏名欄を上に詰めた場合は、下の空白も使えます。他の欄などに重なる場合は、重なる相手を表示し、移動を取り消します。

## タイトル・氏名欄と、動かせる得点欄

国語の右端は、お手本のExcelに合わせ、タイトル18pt・太字・中央寄せ、氏名欄16pt・太字・下寄せで表示します。氏名欄の幅は9.525mm、タイトル欄は約14.393mm、氏名の括弧内は全角スペース8文字です。縦に並ぶ文字の間隔、文字列の上下位置、最初の行と下余白の高さもお手本に合わせています。「その他」→「用紙と表示の設定」で文字サイズを変更でき、配置を「上に詰める」に切り替えることもできます。

**右下の得点欄は、欄全体をつかんでドラッグすると移動できます。** 解答用紙・模範解答・描画の各タブで使えます。スマホは指で移動でき、キーボードでは得点欄にフォーカスして矢印キー（Shiftで大きく移動）も使えます。ドラッグ中のEscで取り消し、「戻す・やり直す」にも対応します。

移動先は作業ファイルに保存し、印刷にも反映します。Excelにも同じ位置で**1つの図形グループ**として出力するので、Excel上で位置を直すこともできます。知識・技能／思考・判断・表現／合計の点数は、配点の変更に合わせて更新されます。
