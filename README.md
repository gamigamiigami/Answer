# 解答用紙メーカー（Answer）

中学校・高校の教師向け。定期テストの解答用紙と模範解答を、キーボードだけで素早く作るオフラインのツールです。

## 使いはじめ

**`answer-sheet-maker.html` をダブルクリック**するだけです。インストールは要りません。通信も一切しません。

- 使い方 → [docs/USAGE.md](docs/USAGE.md)
- 仕様と設計の根拠 → [docs/SPEC.md](docs/SPEC.md)
- お手本にしたExcel → [docs/reference/](docs/reference/)

## できること

- 数字キー1〜7で解答欄を置く（記号・漢字・字数指定の記述・答えのみ・グラフ・自由枠）
- 記述は1列に入り切らなければ自動で列を分ける（50字→25字×2列）。8割ラインつき
- セルを選んで D / Q / P / M / A で番号を振る（大問・問・(1)・①・ア）
- 模範解答タブで答えを入れると、同じ枠に1マス1文字で載る（ズレません）
- Excel出力が正本。解答用紙と模範解答の2シート、印刷設定込み。出力後にExcelで手直しできます
- 必ずA4・1枚。はみ出す置き方はできません
- Ctrl+Z で何度でも戻せます

## 公開ページ用の版を作り直す

`answer-sheet-maker.html` を直したら、次のコマンドで公開用の版を作り直します。

```
node tools/build-artifact.mjs
```

`dist/artifact.html` ができます。これは `answer-sheet-maker.html` から外枠のタグを外しただけのもので、中身は同じです。手で編集しないでください。
