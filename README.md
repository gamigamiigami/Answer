# てすとも君

開始画面の右下と編集画面のロゴ下にアプリのバージョンを表示します。サイト更新時は `answer-sheet-maker.html` の `APP_VERSION` を更新してください。表記は `1.0.0` 形式（機能追加は中央、不具合修正は末尾を増やす）です。作業ファイルのデータ形式番号とは別に管理します。

## A3横の見開き（2026-11-01）

共有された他教科の原本を確認し、大問見出しを欄の上に置く選択肢、同じ行の欄の下端揃え、広い記述欄、⑴・Ⅰなどの番号の読み取りを追加しました。詳細は [使い方](docs/USAGE.md) を参照してください。

国語以外で、全ページがA4縦・横書きの用紙は、2ページ以上になるとA3横の見開きになります。プレビューは左に1ページ目、右に2ページ目。3ページ目以降は3・4、5・6の順です。反対側の用紙をクリック、またはTabで選んでEnterを押すと編集対象が切り替わります。最後が奇数ページなら右側は空白です。

模範解答から作る際、A4縦に収まらない内容は読み書きできる大きさで自動分割します。既存の縮小された用紙は「ページ・画像」→「読みやすい大きさで分割」で分けられます。1問・完答の組は途中で分割しません。1問だけでA4を超える場合は縮小されるため、倍率と文字の大きさを確認してください。

PDF・ブラウザー印刷はA3横に2ページを並べます。印刷画面ではA3横、余白なし、100%、ヘッダー・フッターなしを指定してください。Excel出力は編集用のA4ページ別シートを維持します。1ページの用紙、国語、縦横が混在する用紙は従来のA4出力です。模範解答の編集画面は現在選んでいる1ページを更新します。


テスト作成のお供「てすとも君」。中学校・高校の教師向けに、定期テストの解答用紙と模範解答を、キーボードだけで素早く作るツールです。

- **`answer-sheet-maker.html` をダブルクリックするだけ**で開きます。インストール不要
- **通信は一切しません。** 問題も答えも外に出ません。ネットを切っても全機能が動きます
- 出力は **Excel（.xlsx）が正本**。各ページに解答用紙と模範解答の2シート。出力後にExcelで手直しできます
- 各ページは **A4の縦・横を選択可能**。A4を超える内容も生成し、倍率を自由に調整。1枚への縮小と、読みやすい大きさでのページ分割を選べます

使い方 → [docs/USAGE.md](docs/USAGE.md)　／　仕様と設計の根拠 → [docs/SPEC.md](docs/SPEC.md)

## できること

| 分類 | 中身 |
|---|---|
| 模範解答から作る | 番号・答え・点数・知／思を入力して生成。個別編集・一括採点・入力窓の再編集に対応 |
| 欄を置く | シンプル枠／記号用／文字数（8割ラインつき）／長方形／xyグラフ |
| まとめて置く | 範囲を選んで1キー。記号16個が2操作 |
| 番号を振る | 大問・問・(1)・①・ア。選んだ番号欄だけに順番に入る |
| 配点 | 欄ごと、または範囲を選んでまとめて。合計100でなければ警告 |
| 模範解答 | 別タブで入力。同じ枠から作るのでズレない |
| 描画 | 直線・点。作図の下図やグラフの補助線に |
| 表 | 列×行で作成。行・列の追加削除、セル入力、見出しと模範解答の切り替え、Excelの表として出力 |
| 出力 | Excel（正本）／PDF（確認用）／作業ファイル(.json) |

罫線の寸法は、作成者が自作していたマクロ付きExcel（[docs/reference/](docs/reference/)）に合わせてあります。
1文字マスは印刷時 **幅10.16mm × 高さ7.62mm**。えんぴつで書ける大きさです。

## 公開（GitHub Pages）

既定ブランチに push すると、GitHub Actions が自動で公開します。

```
https://gamigamiigami.github.io/Answer/
```

- このURLを開くと、そのまま道具が使えます。ポータルサイトからはここにリンクしてください
- `https://gamigamiigami.github.io/Answer/answer-sheet-maker.html` は同じ中身です。
  「名前を付けて保存」で各自のPCに持ち帰る用のリンクとして使えます

Pages は設定済みです（Settings → Pages → Source が「GitHub Actions」）。
以後は既定ブランチに push するだけで自動更新されます。

公開の中身は `site/` で、`node tools/build-site.mjs` が作ります（リポジトリには入れません）。
公開前に「タイトルがあるか」「通信のコードが無いか」を自動で点検します。

## ポータルサイトに載せる場合

上の GitHub Pages のURLにリンクするのが一番簡単です。
自分のサーバーに置きたい場合は、`answer-sheet-maker.html` を**そのままアップロードするだけ**です。
1ファイルで完結していて、外部のライブラリもフォントも読み込みません。サーバー側の設定も要りません。

- リンクから開いてそのまま使えます
- 「右クリック→名前を付けて保存」で各自のPCに持ち帰り、オフラインで使うこともできます
- サーバーに置いた場合、Excel・PDF・作業ファイルの保存はすべて普通に動きます
  （PCのファイルとして直接開いた場合のみ、ブラウザの制限でファイル名が失われることがあります）

配布用に添える一文の例：

> テストの解答用紙を作るツールです。リンクを開いてそのまま使えます。
> 保存して各自のパソコンで開けば、ネットにつながっていなくても使えます。
> 作った解答用紙はExcelで出力され、あとから自由に手直しできます。

## 開発

`answer-sheet-maker.html` が唯一の本体です。ここだけ直します。

```
node tools/build-site.mjs      # GitHub Pages 用の site/ を作る
node tools/build-artifact.mjs  # claude.ai の公開ページ用 dist/artifact.html を作る
```

どちらも本体から作り直すだけで、中身は同じです。手で編集しないでください。


自動生成の使い方と入力例 → [docs/USAGE.md](docs/USAGE.md#模範解答から作る)。指定のない配点・観点は未指定・推定として確認できます。作成後は上部の「模範解答の編集」で一覧を開き直せます。

開発時の自動生成テスト：

```sh
node tools/test-answer-generator.cjs
node tools/test-ui.cjs
node tools/test-auto-fit.cjs
node tools/test-graph-answers.cjs
```

テストには Playwright、Chromium、Python 3 と openpyxl を使用します。アプリ本体の利用・ビルドに追加依存はありません。

現在のバージョンは Ver. 2.5.0。今後は変更の検証後、公開ブランチへのpush・GitHub Pagesの公開・公開サイトでの確認まで行います。


## カスタムとセル寸法（Ver. 2.2.0）

全教科でカスタムA・Bの2ボタンを使えます。「カスタムを設定」からボタン名とセル数（1〜40）を保存し、いつでも変更できます。縦書きは縦に指定セル数、横書きは横に指定セル数・高さ2セルで配置します。設定は同じブラウザーで引き継ぎます。配置済みの欄は設定変更で変形しません。

漢字欄の10マスは10セルを意味します。縦書きは幅1列・高さ10セル、横書きは幅10列・高さ2セルです。文字は枠内に収まるよう縮小します。横書きのシンプル枠は未選択時に高さ2セルで配置します。


## 入力方法の選択（Ver. 2.3.0）

「模範解答から作る」の①で点数・観点を決め、②で入力表か一括入力を選びます。初めての方には入力表をおすすめします。一括入力を選ぶと、￥区切りの入力例と大問・問番号・答え・点数・観点の色付き説明を表示します。点数・観点は省略すると①の設定を使います。入力表は列ごとに入力して一覧に反映します。


## 一括寸法・漢字の表示（Ver. 2.4.0）

「まとめて変更」の形式で自由記述を選ぶと幅・高さ（1〜40）を指定できます。全問・選択した問題・大問の範囲に適用し、他の問題の寸法は保ちます。

漢字欄は普通の罫線を使います。模範解答は11pt固定をやめ、欄の幅・高さと答えの長さから収まる最大サイズを探します。縦10セル・横10列の寸法は維持し、画面・一覧プレビュー・Excelで同じ文字サイズを使用します。


## 問番号を付けない階層（Ver. 2.4.1）

「問一」等を使わず、「（１）①」「（１）②」の2段階で番号を付けられます。例えば次の入力で、②は直前の（１）を引き継ぎます。

```text
（１）①￥ア
②￥イ
（２）①￥ウ
```

「（１）￥①￥ア」のように区切る方法、「（１）① ア」のように空白で答えを続ける方法も使えます。「（１）」だけの行を置き、次の行から「①￥ア」「②￥イ」と書くこともできます。縦書き・横書き・Excel・再編集で階層を保持します。


## 全問編集と一枚への作り直し（Ver. 2.5.0）

「模範解答の編集」は選択範囲や現在のページに関係なく全ページの全問を一覧と一括入力へ読み込みます。反映時は全問から用紙全体を新しく作り直して置き換え、結果が1ページなら以前の残りページを削除します。元の複数ページには「戻す」で戻せます。


用紙名の入力中は、Backspace・Delete・Ctrl+A等を文字の編集として扱い、用紙上の欄の削除・選択を実行しません。Enterまたは入力欄を離れると全ページのタイトルへ反映します。番号を引用符で囲んだ「"（１）"￥①￥ア」も、括弧番号と丸数字の階層として読み取ります。
