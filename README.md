# 解答用紙メーカー

中学校・高校の教師向け。定期テストの解答用紙と模範解答を、キーボードだけで素早く作るツールです。

- **`answer-sheet-maker.html` をダブルクリックするだけ**で開きます。インストール不要
- **通信は一切しません。** 問題も答えも外に出ません。ネットを切っても全機能が動きます
- 出力は **Excel（.xlsx）が正本**。解答用紙と模範解答の2シート。出力後にExcelで手直しできます
- 用紙は必ず **A4・1枚**

使い方 → [docs/USAGE.md](docs/USAGE.md)　／　仕様と設計の根拠 → [docs/SPEC.md](docs/SPEC.md)

---

## できること

| 分類 | 中身 |
|---|---|
| 欄を置く | シンプル枠／記号用／文字数（8割ラインつき）／長方形／xyグラフ |
| まとめて置く | 範囲を選んで1キー。記号16個が2操作 |
| 番号を振る | 大問・問・(1)・①・ア。選んだ番号欄だけに順番に入る |
| 配点 | 欄ごと、または範囲を選んでまとめて。合計100でなければ警告 |
| 模範解答 | 別タブで入力。同じ枠から作るのでズレない |
| 描画 | 直線・点。作図の下図やグラフの補助線に |
| 出力 | Excel（正本）／PDF（確認用）／作業ファイル(.json) |

罫線の寸法は、作成者が自作していたマクロ付きExcel（[docs/reference/](docs/reference/)）に合わせてあります。
1文字マスは印刷時 **幅10.16mm × 高さ7.62mm**。えんぴつで書ける大きさです。

## ポータルサイトに載せる場合

`answer-sheet-maker.html` を**そのままアップロードするだけ**です。1ファイルで完結していて、
外部のライブラリもフォントも読み込みません。サーバー側の設定も要りません。

- リンクから開いてそのまま使えます
- 「右クリック→名前を付けて保存」で各自のPCに持ち帰り、オフラインで使うこともできます
- サーバーに置いた場合、Excel・PDF・作業ファイルの保存はすべて普通に動きます
  （PCのファイルとして直接開いた場合のみ、ブラウザの制限でファイル名が失われることがあります）

配布用に添える一文の例：

> テストの解答用紙を作るツールです。リンクを開いてそのまま使えます。
> 保存して各自のパソコンで開けば、ネットにつながっていなくても使えます。
> 作った解答用紙はExcelで出力され、あとから自由に手直しできます。

## 公開用の版を作り直す

`answer-sheet-maker.html` を直したら次を実行します。

```
node tools/build-artifact.mjs
```

`dist/artifact.html` ができます。これは外枠のタグを外しただけで中身は同じです。手で編集しないでください。
