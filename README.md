# てすとも君

## 学年・テスト名と罫線の編集（Ver. 2.10.0）

上部の「学年」「テスト名」を別々に編集できます。Enterまたは入力欄から移動すると、全ページのタイトル・学年・テスト名・氏名欄へ反映します。文字入力中は解答欄追加などのショートカットを動かしません。

罫線を消すには「細かな編集」→「解答用紙」→「配置」を開き、用紙上をドラッグして範囲選択します。「選択した部分の罫線」で、すべて／上側／下側／左側／右側を選び、「選択した罫線だけ消す」を押します。大問や問番号の枠にも使えます。問題・番号・答えを削除せず、選択した線だけを消します。「戻す」で取り消せます。

罫線の削除位置は用紙に保存し、プレビューとExcelの両方に反映します。削除後に欄を移動した場合も削除位置は同じ場所に残るため、配置を決めてから罫線を調整してください。模範解答から用紙全体を作り直すと、罫線も新しい配置で再生成します。

## 入力表は3項目、欄の調整は一覧で（Ver. 2.9.0）

入力表に書くのは「大問・番号・答え」の3項目です。Excelからもこの3列で貼り付けます。点数・観点は答えの下に確認用として表示し、変更は「まとめて変更」タブで行います。大問の範囲やチェックした問題への一括変更に対応します。入力中の設定タブには形式選択を出しません。

新しい問題の欄は答えから自動判定し、一覧の「欄の種類」で調整します。作成済みの一覧から入力表へ戻った場合は、変更していない問題の設定を保持します。

カスタムA・Bは、好きな名前とセル数を登録して使う、ひと続きの枠です。縦書きでは指定セル数を縦方向、横書きでは横方向に使います。一覧でカスタムを選ぶと名前・セル数の説明と「名前・セル数を設定」が現れ、その場で編集できます。「まとめて変更・配置」タブや、細かな編集の「カスタムを設定」からも同じ設定を開けます。設定はブラウザに保存し、同じカスタムを選ぶ欄で共有します。

カスタム欄の模範解答出力では、枠全体と内側の文字の結合範囲が重ならないようにし、Excelでも文字を保持します。

Ver. 2.8.1：まとめて変更の画面を「1. 変更する問題を選ぶ → 2. 変更後の内容を決める → 3. 内容を確認して適用」に整理しました。大問の範囲を1行で表示し、点数・観点・欄の種類を分けて配置します。「今のまま」は変更しません。適用前に対象の問題数と変更後の内容を表示し、画面下の「○問に変更を適用する」で反映できます。

## 入力しながら点数・観点を設定（Ver. 2.8.0）

入力方法を選ぶ前の点数・観点設定を外しました。教科を選んだら入力表または一括入力へ進めます。入力表の「まとめて変更」、一括入力の「点数・観点を変更」タブで、全問・大問の範囲ごと・チェックした問題を選べます。

大問の範囲は複数追加でき、それぞれ点数・観点・形式を指定できます。空欄・「変更しない」の項目を保持し、重なる範囲は下の設定を優先します。チェックした問題は入力表の行のチェック、または設定タブの問題一覧から選びます。範囲外の問題は元の値を保ちます。一括入力の省略時の初期値は設定タブ内の詳細にあります。

連番は直前の全角・半角を保持します。例：`（１）→（２）`、`問一（９）→問一（１０）`、`(1)→(2)`。親の番号を変えず末尾を進めます。

Ver. 2.7.0：入力表で1問追加すると大問・点数・観点・形式を入力済みにし、末尾の番号を連番にします。入力表の「まとめて変更」タブで、全問・大問ごとの点数・観点・形式も変更できます。自由欄の標準は国語が幅1×高さ10、その他が幅10×高さ1です。

**模範解答を入力 → 用紙を確認 → Excel出力。** 初めての方は「模範解答を入力して始める」→「入力表を開く（おすすめ）」から進めます。

Ver. 2.6.0では、基本画面を確認・Excel出力に整理しました。配置・描画・用紙設定は「細かな編集」、見本・白紙は「ほかの作り方」タブへ。一括入力の例は3行に絞り、落ち着いた配色に統一しています。手順は [かんたんガイド](docs/USAGE.md) を参照してください。

開始画面と編集画面の下部にアプリのバージョンを表示します。サイト更新時は `answer-sheet-maker.html` の `APP_VERSION` を更新してください。表記は `1.0.0` 形式（機能追加は中央、不具合修正は末尾を増やす）です。作業ファイルのデータ形式番号とは別に管理します。

## A3横の見開き（2026-11-01）

共有された他教科の原本を確認し、大問見出しを欄の上に置く選択肢、同じ行の欄の下端揃え、広い記述欄、⑴・Ⅰなどの番号の読み取りを追加しました。詳細は [使い方](docs/USAGE.md) を参照してください。

国語以外で、全ページがA4縦・横書きの用紙は、2ページ以上になるとA3横の見開きになります。プレビューは左に1ページ目、右に2ページ目。3ページ目以降は3・4、5・6の順です。反対側の用紙をクリック、またはTabで選んでEnterを押すと編集対象が切り替わります。最後が奇数ページなら右側は空白です。

模範解答から作る際、A4縦に収まらない内容は読み書きできる大きさで自動分割します。既存の縮小された用紙は「ページ・画像」→「読みやすい大きさで分割」で分けられます。1問・完答の組は途中で分割しません。1問だけでA4を超える場合は縮小されるため、倍率と文字の大きさを確認してください。

PDF・ブラウザー印刷はA3横に2ページを並べます。印刷画面ではA3横、余白なし、100%、ヘッダー・フッターなしを指定してください。Excel出力は編集用のA4ページ別シートを維持します。1ページの用紙、国語、縦横が混在する用紙は従来のA4出力です。編集画面は全ページの全問を読み込みます。通常は配置を保って反映します。


テスト作成のお供「てすとも君」。中学校・高校の教師向けに、定期テストの解答用紙と模範解答を、キーボードだけで素早く作るツールです。

- **`answer-sheet-maker.html` をダブルクリックするだけ**で開きます。インストール不要
- **通信は一切しません。** 問題も答えも外に出ません。ネットを切っても全機能が動きます
- 出力は **Excel（.xlsx）が正本**。各ページに解答用紙と模範解答の2シート。出力後にExcelで手直しできます
- 各ページは **A4の縦・横を選択可能**。A4を超える内容も生成し、倍率を自由に調整。1枚への縮小と、読みやすい大きさでのページ分割を選べます

## カスタムとセル寸法（Ver. 2.2.0）

全教科でカスタムA・Bの2ボタンを使えます。「カスタムを設定」からボタン名とセル数（1〜40）を保存し、いつでも変更できます。縦書きは縦に指定セル数、横書きは横に指定セル数・高さ2セルで配置します。設定は同じブラウザーで引き継ぎます。配置済みの欄は設定変更で変形しません。

漢字欄の10マスは10セルを意味します。縦書きは幅1列・高さ10セル、横書きは幅10列・高さ2セルです。文字は枠内に収まるよう縮小します。横書きのシンプル枠は未選択時に高さ2セルで配置します。


## 入力方法の選択（Ver. 2.3.0）

「模範解答から作る」の①で点数・観点を決め、②で入力表か一括入力を選びます。初めての方には入力表をおすすめします。一括入力を選ぶと、￥区切りの入力例と大問・問番号・答え・点数・観点の色付き説明を表示します。点数・観点は省略すると①の設定を使います。入力表は列ごとに入力して一覧に反映します。


## 一括寸法・漢字の表示（Ver. 2.4.0）

「まとめて変更」の形式で自由記述を選ぶと幅・高さ（1〜40）を指定できます。全問・選択した問題・大問の範囲に適用し、他の問題の寸法は保ちます。

漢字欄は普通の罫線を使います。模範解答は11pt固定をやめ、欄の幅・高さと答えの長さから収まる最大サイズを探します。縦10セル・横10列の寸法は維持し、画面・一覧プレビュー・Excelで同じ文字サイズを使用します。


## 問番号を付けない階層（Ver. 2.4.1）

「問一」等を使わず、「（１）①」「（１）②」の2段階で番号を付けられます。例えば次の入力で、②は直前の（１）を引き継ぎます。

```text
（１）①￥ア
②￥イ
（２）①￥ウ
```

「（１）￥①￥ア」のように区切る方法、「（１）① ア」のように空白で答えを続ける方法も使えます。「（１）」だけの行を置き、次の行から「①￥ア」「②￥イ」と書くこともできます。縦書き・横書き・Excel・再編集で階層を保持します。


## 全問編集と一枚への作り直し（Ver. 2.5.0）

「問題・答え・解答欄を編集」は選択範囲や現在のページに関係なく全ページの全問を一覧と一括入力へ読み込みます。反映時は全問から用紙全体を新しく作り直して置き換え、結果が1ページなら以前の残りページを削除します。元の複数ページには「戻す」で戻せます。


用紙名の入力中は、Backspace・Delete・Ctrl+A等を文字の編集として扱い、用紙上の欄の削除・選択を実行しません。Enterまたは入力欄を離れると全ページのタイトルへ反映します。番号を引用符で囲んだ「"（１）"￥①￥ア」も、括弧番号と丸数字の階層として読み取ります。


## 枠内に全文を表示する文字サイズ（Ver. 2.5.1）

漢字・語句・自由記述などの連続した模範解答は、一定の文字サイズまで縮小しても入りきらなかった場合の打ち切りをやめ、全文が入る最大サイズを探索します。漢字は固定の枠寸法を保ち、短い答えを大きく、長い答えを必要な分だけ縮小します。画面・一覧プレビュー・Excelは同じ文字列と文字サイズを使います。字数指定や初終の指定文字数は従来どおり検証します。

### Ver. 2.11.0：入力と確認を行き来しやすく

上部に、このブラウザーへの用紙・答えの一時保存状態と時刻を表示します。変更後は約0.8秒で保存し、失敗時はその旨を表示します。用紙のみ保存・閉じると消す設定も明示します。「編集用ファイルを保存」は後日このサイトで開くためのJSON保存、Excelは配布・印刷用です。「問題・答え・解答欄を編集」から番号・配点・観点・欄の種類も編集できます。入力表・一覧の変更は用紙へ反映するまで一時保存の対象外です。


### Ver. 2.11.2 確認画面の表示

確認・Excel出力では案内と操作バーを隠し、用紙の表示領域を広げました。解答用紙／模範解答の切替・ページ選択・ズームは「細かな編集」で使えます。バージョンと更新履歴はトップページだけに表示します。保存状態の表示は引き続き上部で確認できます。


### Ver. 2.11.3 学年の表示

タイトルには入力したテスト名だけを表示し、学年は氏名欄に表示します。例：学年「二」、テスト名「テスト」なら、タイトルは「テスト」、氏名欄は「二年　組…」です。以前の自動生成による「二 テスト」「二年 テスト」は、保存ファイルや前回の続きの読み込み時にテスト名のみへ修正します。独自に変更したタイトルは保持します。


### Ver. 2.12.0 初終の部分編集

「細かな編集」→「解答用紙」で初終の欄を選び、解答欄タブの「選んだ初終を部分編集」を押します。初め・終わりの文字を空欄にすると文字だけを消せます。「初め側の見出しセルを残す」のチェックを外すと、そのセルだけを取り除いて残りを詰めます。終わり側も独立して変更でき、左右（縦書きでは上下）の解答マス数も個別指定できます。番号・配点・模範解答は保持し、保存・Excelにも反映します。元に戻すで取り消せます。見出しを選んでDeleteを押した場合は文字だけを消し、欄全体は削除しません。部分選択で「削除 ↑」を使うと部分編集を開きます。用紙全体を模範解答の一覧から再生成すると、手動で変更した形は再生成されます。


### Ver. 2.13.0 手動配置を保って答えを更新

既存の用紙では、答え・配点・観点を変更して「配置を保って更新」を押すと、全ページの欄の位置、描画・画像、罫線削除、初終の部分編集などをそのまま保持します。既存問題のIDで対応付けし、全ページを検証した後にまとめて更新します。変更により問題数・番号・種類・寸法が変わる場合や、答えが現在の欄に収まらない場合は用紙を変更せず案内を表示します。「まとめて変更・配置」の反映方法から「一覧の全問から用紙を作り直す」を選べば、従来通り全体を再配置し、余分な旧ページを残しません。取り消しで全ページを元に戻せます。


200％拡大時はスクロールバーの有無に依存しない表示計算とし、用紙のflex縮小とスクロールアンカーを無効にして再描画時の揺れを防ぎます。初終の見出しで「削除 ↑」を押すと、初め／終わりの選んだ見出しだけを外し、解答マス数を保持して枠の末尾まで再計算します。初終への通常挿入を妨げていた部分編集への分岐も解除しました。


### Ver. 2.13.1 初終の字数変更

一括入力や一覧で初終3字から初終4字などへ変更した場合も、同じ問題として配置を保って更新します。欄の始点・見出しの手動編集・IDは保持し、字数に合わせて枠を伸縮します。同じ列（横書きは同じ行）の後続の欄と番号も伸縮分ずらします。ページをはみ出す場合は現在の用紙を変更せず案内します。問番号の全半角・漢数字表記の照合を改善しました。


### Ver. 2.13.2 確認画面の切り替えとズーム

「確認・Excel出力」でも、コンパクトな操作バーから「解答用紙／模範解答」を切り替え、「−／画面に合わせる／＋」で画面の表示倍率を変更できます。印刷やExcelの大きさには影響しません。不要な案内文や更新履歴は表示しません。


### Ver. 2.13.3 大きな枠の端だけを消す

「細かな編集」→「解答用紙」で、大問の大きな枠や見出し枠の端のセルを選び、Delete（または「消す」）を押すと、選んだセルに接する罫線だけを消します。大問名・問題・答え・配点と残りの枠は保持します。複数セルの範囲選択にも対応します。枠全体を選んだ場合は従来どおり全体の削除となります。「元に戻す」、保存、配置を保った答え更新、Excelにも対応します。方向を限定する場合は「配置」→「選択した罫線だけ消す」を使います。


### Ver. 2.13.4 消した枠の場所を再利用

大きな枠の端でDeleteしたセルは、移動時に元の枠・見出しの占有判定から除きます。新しく置く欄・シンプル枠はその場所に自分の罫線を表示します。実際に残っている解答欄、タイトル、氏名欄の占有は解除しません。以前の版で消した箇所も、保存済みの罫線削除情報から判定します。取り消し、保存・再読み込み、配置を保った答え更新、Excel出力にも対応します。


### Ver. 2.13.5 入力表の連続入力

入力表の「問題を入力」タブでは、Shift＋Enterで末尾に1問追加し、新しい答え欄へカーソルを移します。「＋1問追加」ボタンも同じ動きです。大問・点数・観点は直前の行を引き継ぎ、番号は末尾の番号を連番にし、答えは空欄で追加します。Enterだけなら改行、日本語変換中のキー操作では追加しません。まとめて変更タブではショートカットを実行しません。200問に達した場合は追加せず案内します。


### Ver. 2.13.6 枠を引き直す

シンプル枠（1）は、同じ範囲で繰り返し使っても枠を外さず、選択中の線の太さで枠を整えます。削除済みの罫線がある場合も、新しい枠の外周に限って削除指定を解除して線を引き直します。外周以外の消した線は戻しません。消した場所の再配置判定は保持します。罫線を消す操作にはDelete／罫線だけ消すを使います。
